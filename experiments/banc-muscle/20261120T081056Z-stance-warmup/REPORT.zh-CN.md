# 六足站姿、感觉预热与 BANC 接管

独立 BANC—肌肉身体研究已增加可运行的站立入口。已验收的准备流程使用 1 ms 派生地面和规范 90 肌肉身体。算法先稳定承重 250 ms，再让身体保持站立并预热感觉 250 ms，随后在同一物理回合撤掉算法，由现有 BANC 模型独立出肌肉命令。预热通过，神经接管后的持续站立未通过。此版本为手动研究实现。

## 站姿如何得到

同时搜索胸部高度和倾角、42 个关节角与 90 路初始肌肉张力。用原生逆动力学平衡重力、被动力、接触和肌肉力，并约束各腿负载、跗节侧别和临近腿网格间距。已选姿态、初始激活、关节和肌肉名称、规范 XML 哈希均在 stance.json。归一化最大静力残差 1.11×10⁻¹³。胸部自由根高 2.017 mm，投影质心距支撑多边形最近边 0.151 mm。各足载约为体重的 6.5%、37.0%、17.0%、10.9%、24.4%、4.2%，顺序为左前、中、后及右前、中、后。42 个关节均在模型范围内。

不同腿的 1,041 对凸网格按世界坐标顶点逐对验证，最小分离下界 0.0030 mm。股节、胫节和跗节到头、胸和腹部的 294 对网格全部分离，下界 0.00197 mm。站姿的合理性按当前虚拟身体的几何和力学评定。实蝇偏好姿态和逐足负载分布尚待动物运动学资料比对。

准备算法在线读取姿态、速度和激活，以局部线性二次反馈在原生执行器控制范围内调节 55 路有双向调节余量的肌肉，其余保留求出的张力。模拟从该预张力初始化，未测试从零张力或倒地起身。全程额外广义力和躯干外力为零。持续保留算法的 750 ms 正对照全程通过站立门；另从 ±0.03 mm/s 水平初速度启动，两个算法保持对照也通过。扰动证据限于该指定方向和幅度。

## 原地面与派生地面

同一站姿、初始激活、控制律、重力、步长、摩擦及身体分别实跑。原 20 ms 地面在 82.0 ms 出现非足承重，250 ms 时足载为 0.126 倍体重，未进入触觉预热。1 ms 地面通过准备门。批准的派生设置只更改地面几何体的接触时间常数和选择该值所需的优先级；同姿态逐接触核对了其他接触参数、摩擦、接触距离和接触点。原 XML 保留。

原地面还存在一个静态上限。在全身速度与加速度均为零、足面穿透不超过 0.012 mm 时，MuJoCo 3.9 当前设置的跗节法向力总和至多为 0.21442 倍体重。计算对 30 个跗节 mesh 各取最多三个平面接触，全部给足最大允许压入和最大阻抗。单位摩擦、三维金字塔接触和本模型的其余参数下，每个接触的法向力上界为 (0.012+0.002)/(0.020² × 0.05 × 该足段的平移逆权重)。0.002 mm 是组合接触边距。已逐值复核 93 个原生静止逆动力学接触。运动中的瞬时足载可以超过这个上限。原地面与派生地面分别见 FLOORS.json。[MuJoCo 平面—网格接触实现](https://github.com/google-deepmind/mujoco/blob/3.9.0/src/engine/engine_collision_convex.c) · [MuJoCo 约束阻抗实现](https://github.com/google-deepmind/mujoco/blob/3.9.0/src/engine/engine_core_constraint.c)

## 预热和撤手实测

准备门要求最近连续 100 ms 六足各承重超过 1% 体重、总足载 0.98–1.02 倍体重、非足负载为零、穿透不超过 0.012 mm，并达标于既有质心及直立条件。开始预热及放手前都检查。正式预热的 250 ms 内，12 个前腿钟形感器都发放，共 97 次；观测的运动候选根共发放 9,062 次。这里的触觉是前足法向力到钟形感器电流的工程代理。其他触毛和感觉参数沿用上轮检查点的配置。

| 从同一交接时刻算起 | 首次越出站立门 | 质心高度首次降 10% | 首次非足承重 | 最后 100 ms 平均足载 |
| --- | ---: | ---: | ---: | ---: |
| 保留准备算法 | 250 ms 内均通过 | 未出现 | 未出现 | 1.000 倍体重 |
| 预热后撤手，BANC 接管 | 0.1 ms | 57.0 ms | 60.3 ms | 0.187 倍体重 |
| 同姿态冷启动接管 | 9.1 ms | 37.0 ms | 51.4 ms | 0.202 倍体重 |
| 预热后切断运动命令 | 12.1 ms | 15.7 ms | 35.7 ms | 0.374 倍体重 |

所有对照直到交接的身体位置、速度、激活、足载与躯干记录逐值一致。交接保留神经状态、延迟队列、运动尖峰迹与原生肌肉激活。撤手后 2,500 个原生步中，算法供给命令的步数为零；逐步核对了真正送入肌肉的是上一神经区间末端形成的命令。首个 0.1 ms 足载升到 1.520 倍体重，超过 1.2 的站立上限。因此 60.3 ms 是非足负载首发时刻。预热推迟了质心下降和首次非足支撑，尾段足载仍低于冷启动。未拟合神经权重或肌肉翻译层。

## 直接运行或重新求解

在项目根目录运行，输出目录可自选。运行依赖独立 BANC 项目已有的网络、接口检查点及规范身体资产。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
venv_body/bin/python -B experiments/banc-muscle/run_stance.py /tmp/banc-warm-release
venv_body/bin/python -B experiments/banc-muscle/run_stance.py /tmp/banc-four-controls --mode all
```

单独求解入口 separate_legs.py 接受已保存的搜索起点和输出路径。以下命令从搜索起点重新生成全部姿态与张力；已验证输出 JSON 与交付姿态逐字节相同。verify.py 另核准新进程重放的 14 个信号数组、切断和保持对照、几何以及原地面的静态上限。

```sh
p=experiments/banc-muscle/20261120T081056Z-stance-warmup
venv_body/bin/python -B "$p/separate_legs.py" "$p/search_seed.json" /tmp/banc-resolved.npz
cmp "$p/stance.json" /tmp/banc-resolved.json
```

早期能承重的窄姿态因右后跗节越过身体中线而排除。后续候选另发现跨腿网格重叠和左前足载不足。其搜索件保存在 search_history/，正式采用的姿态为本目录 stance.json。下一项可直接用本轮的交接记录比较前 10 ms 的逐肌肉命令、实际激活和关节力矩，定位足载冲高来自哪些执行器。
