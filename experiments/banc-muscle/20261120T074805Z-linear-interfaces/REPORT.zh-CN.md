# 独立 BANC 模型的局部线性翻译与已有边 ±8% 试验

两种姿态下，在线足载反馈经神经图使首个肌肉命令出现在 7.0–7.5 ms。首次非足承重推迟约 9 ms，质心下降 10% 的时刻与切断对照相同。12 个 200 ms 回合均未站稳。此版本是独立研究台架，优化器更新次数为零。

## 可学习的量

| 位置 | 参数与初始化 |
| --- | --- |
| 已有 BANC 边 | 共 321,164 条有向边。兴奋、抑制分别保存，按每个原始电导乘以 1+δ，逐边 δ 限在 [−0.08,0.08]，初始为零。文件以已钉住的图哈希和各符号 CSR 的行内升序索引确定逐边顺序。发放阈值沿用基线。 |
| 足载和本体感觉 | 12 个前腿钟形感器各有一个同侧足载系数，初始 0.5 nA/倍体重，电流截到 [0,0.12] nA。此项跳过外骨骼应变，作为工程代理。另给 296 个六腿 FeCO 爪、钩候选逐根留有带方向的角度或速度系数，初始为零。角度用相对本回合初态的 rad，速度用 rad/s，同样限流。未拟合生理增益。毛板、体表触毛、腿外周边需要各自的几何输入。 |
| 腹神经索的缺失输出 | 原 228 个剩余末端中，216 个已校订局部细胞在同标本发布表有合计 12,648 条指向图内局部目标的有向记录。本次为每一对预留独立带符号的有效电导，初值均为零。发布突触数另存，受体符号及功能增益未定。另 12 根没有满足此筛选的候选。 |
| 运动根到肌肉 | 74 路同靶候选含 259 对、207 个运动根。其中 52 个根各由两路共用。对另外 16 路使用同腿同侧条件，得到 960 对功能假设。两组用独立的非负逐对权重。在本轮试验中活动池从等权均值起步，输出为 10 ms 指数衰减尖峰迹的加权和，截到 [0,1]。显式使用同靶掩码即可关闭全部 960 对。单个前足可引起多条腿响应，身体和神经之间没有直接关节指令。 |

同靶等权矩阵秩 66，自由分配候选权重的结构秩为 74。加入 16 路功能掩码后的两数为 72、90。结构秩是候选位置允许达到的代数上限。真实回路发放的相关性、非负权重、肌力和接触约束都会进一步限制能独立产生的动作。

## 同一身体上的配对结果

每个回合从静息、零肌肉激活开始。每 0.5 ms 读一次当前足载，经过电导网络，取该区间结束时的运动尖峰生成下一段身体命令。MuJoCo 原生步长 0.1 ms，沿用规范身体和内部最小控制量。站立门沿用基线后 100 ms 的足载范围、承重足数、非足载、质心和直立条件。下表每格顺序为历史六足姿态、关键帧姿态。

| 接口配置 | 首个肌肉命令 ms | 首次非足承重 ms | 后 100 ms 平均足载 / 体重 |
| --- | --- | --- | --- |
| 感觉切断 | 无、无 | 25.0、25.1 | 0.239、0.254 |
| 运动切断 | 无、无 | 25.0、25.1 | 0.239、0.254 |
| 仅 74 路同靶池，原边 100% | 7.5、7.0 | 34.0、34.2 | 0.184、0.210 |
| 再接 16 路功能池，原边 100% | 7.5、7.0 | 34.0、34.4 | 0.183、0.202 |
| 同上，原边整体 92% | 7.5、7.5 | 33.3、34.4 | 0.208、0.174 |
| 同上，原边整体 108% | 7.5、7.0 | 34.4、34.9 | 0.179、0.184 |

两姿态的质心下降 10% 在全部条件下分别为 10.5、11.2 ms。接通后所有回合至少一个肌肉命令到达上限。感觉切断后观察到的感觉与运动根均静默，运动切断时仍有神经尖峰；两种切断的身体足载、躯干、激活和时间均逐值复现对应被动轨迹。结果支持工程接口确实作用到身体，尚不能分解初始预张力、肌肉力臂和接触几何各自的贡献。

Pugliese 等研究已有突触权重受扰后的运动节律；Shiu 等改变全局权重并补偿感觉输入，评估脑模型预测。本项目使用的逐边硬边界来自用户的工程设定。此次整图同向端点扫描与未来逐边异向学习是两个不同试验。[Pugliese 等](https://www.nature.com/articles/s41586-026-11195-y) · [Shiu 等](https://pmc.ncbi.nlm.nih.gov/articles/PMC11446845/)

## 复跑与参数交接

从项目根目录运行。依赖本项目保留的独立基线及规范身体。verified/PARAMETERS.npz 是本轮初始参数。另存权重后可用 --parameters 指定，检查点含根 ID、执行器名、精确候选标记与图体哈希。vnc_gain_uS 的正、负值分别进入工程兴奋、抑制矩阵。原边的 exc_fraction、inh_fraction 越界、身份错位或参数非有限时读入失败。两个全图端点条件会将逐边比例统一设为指定值。

```sh
p=experiments/banc-muscle/20261120T074805Z-linear-interfaces
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
venv_body/bin/python -B "$p/vnc_candidates.py"
venv_body/bin/python -B "$p/assay.py" "$p/verified"
venv_body/bin/python -B "$p/assay.py" "$p/replayed" --parameters "$p/verified/PARAMETERS.npz"
venv_body/bin/python -B "$p/check.py"
```

独立进程复跑后，96 个轨迹数组和 16 个参数及身份数组全部相同。另检验逐边不同增益、候选正负分流及越界拒绝。下一项可判别的试验是在同一合法姿态下独立改变初始肌肉激活与随后下发的命令，记录 0–15 ms 足载、关节力矩和质心，并把另一姿态留作复核。运动池权重仍需要逐肌力或运动单元响应来约束；仅凭站立得分无法唯一反推天然支配。
