# 独立果蝇神经—肌肉—身体项目的基础修复

本次为独立软件研究，沿用真实 BANC 神经图和规范 90 肌肉 MuJoCo 身体。范围为局部神经回路、身体观测、承重和运动接口。用户明确排除电极与单独颈部仿真。其他研究线在各自目录保留。

## 已修复并复验

- **腹神经索的出边已补回一部分。** 原先只有入边的 600 个节点中，有 372 个具明确乙酰胆碱或 GABA 标签的局部细胞恢复了出边。按 BANC v888 发布数据补回 22,501 条连接，含 13,216 条 ACh 建模兴奋边和 9,285 条 GABA 建模抑制边。新增边中 2,660 条指向腿部运动细胞，354 条指向已登记腿部感觉候选。600 节点内部从无回路变为 251 个节点处于多节点强连通分量。保留父图全部 298,663 条原边和 12,617 个根顺序。逐对来源和突触数见 `LOCAL_EDGES.json`。
- **兴奋、抑制各有一个直接切断对照。** 两个源都在 14.5 ms 发放，靶点第一拍电导差在 17.0 ms 记录到。兴奋边完整时，靶细胞在到达拍发放并重置，同一拍切除时没有发放。抑制边完整时该拍靶膜电位低 3.566 mV。2 ms 传导延迟仍沿用父实验工程值，0.5 ms 是记录该次积分的采样区间。回路的生理增益与功能待验证。
- **足地和本体物理读数已导出。** `body_observations.py` 逐拍取六腿的胫节关节角与角速度、真实求解器的跗节接触数和法向力。同一回合还保存肌肉激活与关节执行力矩。两份旧被动轨迹 12 个已有数组逐值复现。FeCO 爪／钩候选已关联角度／速度的观测字段，所有感觉发放器都仍关闭。
- **运动接口已留给可训练层。** `INTERFACE.json` 固定了 90 路执行器顺序、12,617 根的图哈希和身体版本。按 v888 同靶、同腿、同侧核对，74 路肌肉有候选池，合计 207 个唯一可用运动神经元。16 路仍无同靶候选。另给出 5,201 个同腿同侧的功能假设配对，初始未启用。强度留空，未把任一功能假设登记成解剖连接。训练时可按根 ID 和执行器名分配自己的权重，任何输出均落在肌肉控制接口的 [0,1] 域内。

## 承重结果

两个旧被动初态在第 0 拍分别只有 0.621 和 0.552 倍体重的足载，约 10.5–11.2 ms 后全身质心已下降 10%，约 25 ms 才首次出现非足承重。这个时序表明早期足部承重已经不足；同时缺少主动肌力维持的健康对照，仍不能单凭先后区分脚地求解与肌肉执行的因果贡献。

同一历史六足姿态，给 90 路施加事前固定的静力松弛解之后，首次非足承重推迟到 40.7 ms，但末段足载反而降到 0.072 倍体重，仍未站稳。保持关节、朝向和 XY 固定，另扫描 21 个启动前根高度；在穿透门内足载最高约 0.633 倍体重，选不出符合门槛的初态。未测试更广的所有合法姿态。

## 仍未知的部分

- 600 个旧靶点中有 228 个仍无建模出边。原始发布有出边的旧靶共 599 个，当前补图要求同版可追溯根、已校订源、明确纯 ACh/GABA 以及图内的局部候选靶。其他递质、受体符号或图外靶点待补。上轮 220 个腿部传入的递质缺口保留，现行 12 个核验过递质的钟形感器仍均在前腿。
- 足地接触读数不提供外骨骼应变、毛板相对关节的精确位置、触毛末梢接触或实际尖峰参数。腿之外的周边扩展、胫节屈肌快中慢的实际电生理留出以及每个肌束的天然支配均待验证。
- 规范身体的稳定承重、实时感觉到神经再到肌肉的闭环、运动切断／重放及扰动恢复仍未建立。此次没有使用可训练层、没有新增权重，也没有让神经记录生成任何肌肉指令。
