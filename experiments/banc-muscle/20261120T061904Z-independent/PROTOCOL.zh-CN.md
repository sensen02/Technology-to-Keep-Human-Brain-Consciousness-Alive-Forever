# 独立 BANC—肌肉身体项目的基础修复

本目录是独立软件研究项目，沿用旧 BANC 模型和规范肌肉身体。范围为腹神经索局部回路、运动细胞候选、物理观测和身体基础诊断。用户明确排除电极和单独的颈部仿真。所有修复均以新派生件登记，其他项目的配置和验收不作为本项目结果。

- 冻结父图 12,617 根与原权重。对 600 个此前只有入边的 VNC 靶点扫描 BANC v888 发布边，以已校订 VNC 局部细胞、已标明纯 ACh 或纯 GABA 的源为准。靶限当前图内的 VNC 内在细胞、带腿部效应标注的运动细胞及上一轮登记的腿部传入。剔除自环及重复；谷氨酸、混合和空标签暂保留为未决。保留 v888 有向边及计数，单位沿用父实验工程值。核对图的全部原项、逐对来源、出边恢复数、600 节点内的强连通分量及 ACh/GABA 各一条单边切断。相同阈值、固定刺激、无外接控制。
- 用规范 90 肌肉身体重放两份零命令被动初态。逐原生拍捕获胫节角/角速度、实际足地法向力和足地接触、躯干及轴力矩。初始化取包内旧姿态，沿用 0.1 ms。核对旧数组。单列历史合法六足姿态加此姿态松弛 LP 的 90 路独立肌肉激活作为恒定输入的物理对照，初态 `act` 同输入，无反馈与辅助，保持 200 ms 与原站立门。静力 LP 值不作为神经命令。
- 为用户后续训练提供明确根 ID 和执行器名的工程配置。解剖候选来自原逐肌肉表及同版元数据的同腿、同侧、精确周边靶名。功能候选为同腿同侧的已标注运动细胞，单列、初始未启用。无数据的强度留空；训练权重与解剖身份分开。机体只暴露物理量，电流、受体位置、应变换算和力标定需要独立数据。

## 初态承重补充对照

在历史合法六足初态上固定所有关节、四元数及 XY。只在仿真启动前将根部 Z 自原值降 0 至 0.010 mm，共 21 个等距候选。取首个满足原初态六足有力、只有足接触、足载 0.98–1.02W 且原生足面穿透不深于 0.012 mm 的候选。若有候选，各做零命令及同一已存 LP 恒定肌肉输入 200 ms。停止后原门不变。该初态筛选只检验初面对身体的影响，不把接地冲击或恒定肌肉输入计作自主承重。
