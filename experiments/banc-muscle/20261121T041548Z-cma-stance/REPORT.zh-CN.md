# 分批 CMA-ES 训练后的 BANC 自主站立

同一六足姿态撤掉准备算法后，原 BANC 于 0.1 ms 首次越出站立门。训练候选连续通过至 141.0 ms，于 141.1 ms 因总足载降至 0.792 倍体重而首次越门。首个非足承重从 60.3 ms 推迟至 159.4 ms。名义初态及两个留出初速均未通过完整 250 ms。本次交付是可继续训练的研究权重。

## 原入口独立复验

规范的 90 肌肉身体、1 ms 派生地面和姿态文件均沿用通过准备验收的版本。起始算法站立 250 ms，继续保持姿态并预热感觉 250 ms。放手后 2500 个原生步的教师供给次数为零。每次实际肌肉命令都核对为上一神经区间末端的因果尖峰读出。准备张力连续保留，释放后的读出没有恒定张力偏置。主要验收按每个原生步检查承重足数、总足载、非足载、质心高度、直立和穿透深度。所有时间从撤手时刻算起。

| 初始条件与权重 | 首次越门 ms | 质心首次降 10% ms | 首次非足承重 ms | 后 100 ms 平均足载 / 体重 |
| --- | ---: | ---: | ---: | ---: |
| 原权重，名义 | 0.1 | 57.0 | 60.3 | 0.187 |
| 训练候选，名义 | 141.1 | 146.2 | 159.4 | 0.074 |
| 训练候选，初速 +0.03 mm/s | 142.4 | 148.1 | 159.6 | 0.076 |
| 训练候选，初速 −0.03 mm/s | 42.2 | 58.1 | 64.5 | 0.004 |
| 将已有突触恢复原值，保留已学接口 | 29.0 | 86.0 | 97.4 | 0.074 |
| 保留已学原边，接口恢复初值 | 0.1 | 56.9 | 60.1 | 0.076 |
| 名义初态，交接时切断运动命令 | 12.1 | 15.7 | 35.7 | 0.374 |

两个留出初速都在准备开始前施加。冻结参数后才用于检验；撤手后突然施扰的恢复能力仍待测。原权重在两个留出初速均于 0.1 ms 越门。训练候选在负初速上较早失载。名义条件交接后首拍足载从 1.520 降至 1.146 倍体重，已在允许范围内。141.1 ms 时仍有三足承重且非足载为零，质心保留 93.9%，首先触发总足载下限。末窗足载低于原模型，改进集中在前半段。STANCE.png 给出完整曲线。

## 训练了哪些参数

采用带协方差更新的 CMA-ES。每轮只改变一个批次，实际接受的候选才成为下一轮起点。原边从原始电导计算比例，防止分轮微调累积超界。初轮用末段预热尖峰拟合教师张力得到的运动权重在真实释放评分上退步，后续从较好权重继续。训练历经按活动分组的原边、按执行器和运动根分组的肌肉映射、交接冲击最大的逐肌肉方向、FeCO 与未决 VNC 接口，以及在 BANC 自己访问的姿态上离线查询教师作纠偏。优化器累计评估 2,258 个在线闭环候选；这些搜索回合可早停。另有 15,620 个离线预热标签候选与 8,640 个离线纠偏标签候选。正式验收逐回合跑满。名义首次越门从 0.1、40.9、73.8、136.1 到 141.1 ms，第二轮扩大搜索持平。各批参数、候选、评分及优化器状态在对应训练目录。

- 正式候选改变 4,096 条已有兴奋边，幅度 −7.784% 至 +7.796%。已有抑制边参加独立搜索，最终沿用原值。既有 321,164 条边的身份和符号完整保留。神经元发放阈值沿用原值。
- 1,219 个运动根到执行器权重、296 个 FeCO 角度或速度增益、436 条原来关闭的 VNC 功能候选有变化。前腿 12 个负载系数沿用原始 0.5。逐对工程参数与现有突触电导分别导出。运动增益最高 28.64，受输出 [0,1] 截断，名义回合首次越门前约 24.3% 的逐肌肉命令样本处于上限。权重用于虚拟身体控制，其符号和大小尚无逐肌束生理验证。
- 原权重的强度单独恢复后只能撑至 29.0 ms 首次越门，单独恢复工程接口后在第一拍越门。两组消融支持已有突触与翻译层对这一候选的联合作用，不能据此逐根推断天然支配。

## 运行与证据

在项目根目录执行下列命令即可用原站立入口载入此次保存的权重。独立进程重放的 14 个数组逐值相同。CANDIDATE.npz 的 SHA256 为 f0397fa26cb0aa68b0906226eebebb75da3491e8d73a7b58a40618670a66c693。默认模型、原对照和失败权重保留。

```sh
p=experiments/banc-muscle/20261121T041548Z-cma-stance
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
venv_body/bin/python -B experiments/banc-muscle/run_stance.py /tmp/banc-cma-release --parameters "$p/CANDIDATE.npz"
```

ACCEPTANCE.json 包含每组指标与参数改变量，CONNECTION_CHANGES.npz 直接列出变化的根 ID、执行器及前后权重，INPUTS.sha256 钉住代码、输入和优化器版本。Python 3.12.14、NumPy 2.5.3、SciPy 1.18.1、MuJoCo 3.9.0、cmaes 0.11.1。训练可从一个同级新实验目录重放，复制本目录 Python 脚本及 deps 后，设置 PYTHONPATH 指向自带的 cmaes wheel，按顺序执行 bench.py、train.py 新目录内的 training、handoff.py、refine.py、transfer.py、extend.py 两轮和 correct.py。验证、绘图和逐根导出分别用 validate.py、finish.py、plot.py、export_changes.py。完整参数和运行顺序见 PROTOCOL.zh-CN.md 与本目录脚本。

后续最小实验是把训练目标改成多个准备期初速中最差的连续站立时长，同时逐足记录 80–150 ms 中后足卸载及相应髋、胫肌肉命令。已报告的两个留出初速须保留本轮身份，新增初速作下一轮独立验收。
