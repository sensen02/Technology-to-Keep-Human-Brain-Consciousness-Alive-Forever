# 虚拟 TTX 放电阻断：独立 BANC—肌肉身体一轮配对试验

## 问题与边界

本轮检验当前赛博果蝇的 BANC 腹神经索—90 肌肉身体台架在放电阻断下如何变化，关联 P1/P3、S3–S5。依据 [Para 通道原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2233785/) 和 [果蝇神经元 TTX 处理研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3125135/)，TTX 对电压门控钠通道及动作电位的影响是选择“放电阻断”这一模型扰动的动机。本项目点神经元没有显式钠通道，因此**没有模拟 TTX 分子、剂量、扩散、结合、膜电流或暴露时间**。数值操作是在 500 ms 交接时将指定根的发放阈值设为不可达到的工程值；亚阈值积分和阻断前已发出的延迟事件照常保留。它仅是软件因果对照，不是果蝇毒理预测。

## 输入、设计与复验

- 独立项目的 12,617 根 BANC 派生图、既有逐边权重、未训练接口检查点、规范 90 肌肉身体和已验姿态都按哈希固定，结果见 `RESULT.json`。使用已声明的 1 ms 派生地面；原 20 ms 地面未在本轮运行。
- 每组同样运行 250 ms 肌肉算法承重、250 ms 前足感觉预热，然后在不重置身体、神经状态或肌肉活化的情况下撤去算法，观察 250 ms。仅在交接拍更改放电条件。四组依次是无阻断、全 12,617 根、当前 308 个感觉候选根、当前 364 个肌肉读出运动根。后两组是软件选择性干预，并不表示实际药物可按这些根扩散或选择。
- 新入口 `../ttx_spike_block.py`、独立核查与作图 `../ttx_spike_block_audit.py`；没有修改原 `run_stance.py`、`warm_release.py`、模型、检查点或旧结果。每组 7,500 原生物理步、1,500 神经拍，四组合计 30,000 原生步；训练更新 0。
- 四组交接前身体和神经数组逐值相同。无阻断组与既有 `results/warm_release.npz` 的位置、速度、肌肉活化、足载、躯干和神经命令数组逐值相同。阻断组的目标根交接后发放均为零；全根阻断和仅运动根阻断的身体及实际肌肉命令逐值相同。交接后全部教师步数为零，外加广义力和躯干力均为零。

## 同一交接状态的结果

| 阻断范围 | 后 250 ms 神经尖峰 | 运动根尖峰 | 首次质心下降 10% | 首次非足接触 | 末 100 ms 六足载 / 体重 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无 | 105,341 | 9,912 | 57.0 ms | 60.3 ms | 0.18686 |
| 全部点神经元 | 0 | 0 | 48.6 ms | 67.5 ms | 0.04090 |
| 当前感觉候选根 | 110,799 | 10,909 | 57.0 ms | 60.3 ms | 0.15402 |
| 当前运动读出根 | 98,747 | 0 | 48.6 ms | 67.5 ms | 0.04090 |

全根和运动根阻断使实际肌肉命令的时间积分从 14.00282 降至 0.98683（90 路归一化控制量相加再乘秒，约为对照的 7.05%）；剩余部分来自交接前神经尖峰迹的衰减。末段足载从 0.18686W 降至 0.04090W，下降约 78.1%。感觉候选根阻断清零了相应感觉尖峰，但全网及运动根仍发放，末段足载为 0.15402W；这个差异不能在尚未合格的基线上推断天然感觉的重要性。

四组都在交接后 0.1 ms 越出原站立门。无阻断基线本来就不能持续站立，且交接第一拍足载冲到 1.520W；因此**本轮没有证明 TTX 令原本能站立的果蝇瘫倒**。全根阻断的“首次非足接触”反而比对照晚 7.2 ms，不能只选这个指标判断受损程度。全根阻断与运动根阻断在身体层逐值相同，说明当前接口的肌肉输出完全由所列运动根控制；不代表真实果蝇所有运动通路已覆盖。

配对图 `PAIRED_RESPONSE.png` 已实际打开检查。身体形态显示的是当前模型在该短窗内的落地过程；本轮未渲染新的视频，也没有真实动物或实体药物操作。下一最小动作是在同一派生身体上先取得无阻断且撤辅后持续合格的神经站立基线，再做干预后恢复及剂量模型；剂量模型需要独立的通道和暴露数据。

## 命令与环境

项目根目录、`venv_body` Python 3.12、NumPy 2.5.3、MuJoCo 3.9，单线程 BLAS/OMP：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 venv_body/bin/python -B experiments/banc-muscle/ttx_spike_block.py experiments/banc-muscle/20261120T161214Z-ttx-spike-block
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 venv_body/bin/python -B experiments/banc-muscle/ttx_spike_block_audit.py experiments/banc-muscle/20261120T161214Z-ttx-spike-block
```

两条命令退出码均为 0。`AUDIT.json` 全部检查通过，原四组原始数组分别保存在同目录 `.npz` 文件。运行入口拒绝覆盖非空输出目录；复跑须给新目录，独立比较输出结果。
