# 冻结模块的固有腿间节律（预登记，阴性：无左右交替）

只回放已保存的感觉电流，不接入物理、不学习、不改任何参数。目的是给上一轮 53 个物理候选的失败找一个机制层面的解释：冻结模块本身有没有可用于步行的腿间时间结构。

桌面：`/home/sensen/Desktop/engine修复验收/banc-descending-learning/20261107T203049Z/intrinsic/`

## 做法

两个条件各 5000ms（1000 个 5ms 箱，每箱 10 个 0.5ms 神经步 = 10000 神经步），都从同一个 1s 完整检查点恢复，下行电流为 0：

- `held`：感觉电流恒为第一个箱的输入；
- `replay`：把记录的 100 个箱循环回放。

## 结果

每腿平均率（held）：LF 21.2、LH 21.4、LM 8.8、RF 20.9、RH 16.8、RM 13.3 Hz；变异系数 .273–.503。

腿间相关（held）：LF–RF .817、LH–RH .564、LM–RM .381；跨侧 LF–RH .036、RF–LH .082。交替分数 −.036 与 −.082，即**没有反相**。

主导频率：LF 4.0、LH 3.6、RF 3.8、RH 3.6 Hz；LM 2.0、RM 6.4 Hz。

replay 条件下结论相同（交替分数 +.159 / +.031，仍远低于任何可用阈值），且整体相关结构与 held 一致。

主成分（2s 基线窗口）显示这一结构是双侧对称的前/后模态：PC1 49.5% 载荷 LF +.58、RF +.70、LH −.31、RH −.28、LM +.02、RM +.05；PC2 32.6%。三足模式与 PC1 的夹角仅 .22。

## 含义

- 模块自发活动是同侧同步 + 前/后反对称，缺少左右自由度；任何静态同腿读出只能翻译这些模态，因此上一轮的失败是结构性的，而不是搜索运气。
- 这不等于果蝇腹神经索没有交替机制：本模型是 20000 细胞严格过滤子集，受体符号/增益/延迟都未标定，缺失的中间神经元群体可能正是产生交替的部分。
- 本回放不含物理接触，因此既不证明也不能否定任何步态可行性。
