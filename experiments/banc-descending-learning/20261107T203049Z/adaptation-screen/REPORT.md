# 适应电导腿组不对称的神经筛查（预登记，阴性）

只做神经开环筛查，不含物理与学习。目的是检验：在不加入任何外置相位或步态时钟的前提下，把适应电导的脉冲增量按腿组放大，能否把冻结模块的同侧同步打破成左右交替。

桌面：`/home/sensen/Desktop/engine修复验收/banc-descending-learning/20261107T203049Z/`

## 做法

`module_scale.py` 是新的版本化假设文件：子类只把选定神经元的每次脉冲适应增量乘以固定系数，其余方程、参数、状态与输入全部沿用冻结的 192931Z 核心；`range` 约束为系数不小于 1，因此适应电导仍只增不减、仍按冻结 tau 衰减，非负与 −80mV 下界的论证不变。被缩放的只有 323 个导出运动细胞中属于指定腿组的 162 个，其余 19677 个神经元系数为 1。

预登记先跑等价性守卫：全部系数为 1 时必须与冻结核心逐位相同（通过）。之后 5 个方案各 2000ms 开环回放（400 个 5ms 箱，感觉电流回放记录的 100 箱）：

| 方案 | 三足交替分数 | 左右相关 | A = LF,RM,LH | B = RF,LM,RH |
|---|---:|---:|---:|---:|
| 基线（系数 1） | −0.624 | 0.631 | 18.5 Hz | 15.5 Hz |
| 同侧 x2 | −0.574 | 0.561 | 14.9 Hz | 14.7 Hz |
| 三足 x2 | −0.569 | 0.571 | 13.8 Hz | 15.5 Hz |
| 同侧 x4 | −0.418 | 0.369 | 11.3 Hz | 14.1 Hz |
| 三足 x4 | −0.410 | 0.403 | 9.3 Hz | 15.5 Hz |

交替分数为 `−corr(A,B)`，正数才表示左右两组交替。五条全为负，最大只到 −0.410，远低于事先固定的 +0.3 阳性阈值；没有任何方案被判为阳性。`alternation_positive` 为空。

## 为什么阴性很重要

`analyze_modality.py` 对保存的每腿平均率做主成分分析（0 仿真步）：

- 基线 PC1 解释 49.5% 方差，载荷 LF +.58、RF +.70、LH −.31、RH −.28、LM +.02、RM +.05。这是**前足对后足的反对称**，而左右两侧载荷几乎相同。
- PC2 解释 32.6%，LF +.20、RF +.38、LH +.66、RH +.62，同样是左右对称结构。
- 也就是说冻结模块的腿间结构是**双侧对称的前/后模式**，几乎没有左右自由度；而三足步态需要 {LF,RM,LH} 与 {RF,LM,RH} 反向。前/后反对称与三足模式的夹角只有 .22。

只放大运动细胞自身的适应，最多把同侧相关从 .63 压到 .37，仍然不产生左右反相。这与上一轮 53 个读出候选全部失败的机制解释一致：静态同腿读出只能把已有的对称模态翻译成俯仰/整体屈伸，不能凭空造出左右交替。

必须强调：这是**本严格过滤的 20000 细胞子集**的性质，不是果蝇腹神经索的结论。缺失的侧向化中间神经元、未经标定的受体符号与增益都可能是原因；本筛查也没有证明任何参数组合都做不到，只证明“单独放大运动细胞适应”这一条机制在这套模型里不成立。
