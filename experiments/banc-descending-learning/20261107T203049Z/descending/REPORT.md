## 执行与计数

六个固定条件：输入模式（held = 复用同一 5ms 感觉电流行；recorded100 = 回放记录的 100 个 5ms 感觉电流）× 剂量（0 / .025 / .05 nA），各 1000 神经步，全部从同一个 1s 完整检查点恢复；每次恢复后断言状态与 `NEURAL_START.npz` 完全一致。主运行 6000 神经步、物理步 0、优化更新 0；独立重放对两个 .05 条件各再做 1000 步，共 2000 步。本轮该目录合计 8000 神经步。

独立重放手工恢复完整状态、不导入 `command.py` 与 runner，直接调用 `net.step` 与手写滤波器；16 个轨迹数组与 26 个终态字段全部逐值相等；recorded100 零剂量与上一轮保存的 323 运动细胞率/电位、t=1.5s 终值也一致。

父代理对保存数组的进一步分析（`/home/sensen/Desktop/engine修复验收/banc-descending-learning/20261107T203049Z/DESCENDING_EFFECT.json` 与 `DESCENDING_EFFECT.png`，0 步）：

- 每腿平均率变化幅度（|Δ| 均值）2.675 Hz（held）、3.260 Hz（recorded100），而同一条件零剂量下网络自身在 0.1–0.6s 之间的慢漂移每腿 |Δ| 均值是 7.877 Hz 与 8.075 Hz。**下行电流造成的改变比网络自发漂移还小**，比值 .34 / .40。
- 腿间方向不一致，且两种输入模式给出相反符号：held 下 LF −1.37 Hz、LH +1.42 Hz、RF +1.83 Hz；recorded100 下 LF +1.59 Hz、LH −1.08 Hz、RH +0.57 Hz、RM +2.13 Hz。
- 逐细胞 delta 在两个输入模式之间只有中等可复现性：整体 r=0.309、符号一致 .693；分腿 r 为 LF .630、RF .640、LM .472、RH .291、RM .258、LH −.030。

结论：候选下行通道在严格图谱中确实连到运动细胞，并且可以被电流激活；但在当前冻结的局部模块里，一个恒定下行电流没有被放大或组织成腿特异、左右协调的运动程序。它没有产生可用于行走的下行驱动，也**不能**据此说明果蝇腹神经索缺少这种通路，或完整连接体不可能行走——本模块是 20000 细胞的严格过滤子集，受体符号与增益仍未标定。

## 网络自身的节律结构（父代理补充审计）

`/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-descending-learning/20261107T203049Z/intrinsic/`（预登记，2 × 10000 神经步，0 物理步）用同样的感觉电流开环回放 5s：

- 腿间相关呈现**同侧同步**：LF–RF .817、LH–RH .564、LM–RM .381；而三足交替所需的跨侧配对几乎不相关：LF–RH .036、RF–LH .082。交替分数 −.036 / −.082，即没有反向交替。
- 主导频率集中在约 3.5–4.0 Hz（LF 4.0、LH 3.6、RF 3.8、RH 3.6），LM 2.0 Hz、RM 6.4 Hz。

这为上一轮失败提供了一个机制层面的解释：冻结模块的自发结构是同侧共变，而静态同腿读出只能把已有的共变翻译成同侧共同运动，不会自动产生左右交替的支撑序列。
