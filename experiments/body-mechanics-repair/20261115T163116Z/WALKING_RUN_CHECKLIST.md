# S2 身体力学修复首轮

- 父实验为 20261110T152754Z 的有限 PD 步行与 BODY_MUSCLE_REVIEW.zh-CN.md。目标是实现足端几何接触样件、完整身体候选和肌肉参考姿态的兼容转换。
- 足钩样件为工程尺寸。固定同一个表面凸齿和拉力，比较双钩、去掉钩尖的直梁、无凸齿墙面。工程门为低摩擦时钩接触法向沿加载方向承担至少 0.8 倍载荷，承载窗水平移动小于 0.02，撤力后由有限轴向驱动拔出并完全脱离；对照须滑过 0.25。两档步长分别验证。台架不计入整蝇行走。
- 完整身体候选只增加足端自由碰撞几何。用已声明平地姿态核对模型尺寸、质量惯量、关节/执行器、接触标签和初始平地侵入情况。另从已保存平地自主段首帧出发，以同样的 250 个保存目标做两臂有限 PD 回放。门为 20,000 原生步内无实际爪约束，最大位置分量差不超过 1e-7。该对照不具备独立神经行走验收资格。
- 肌肉兼容转换以同次 17 帧保存姿态为输入。固定根位姿及非铰链状态，只在离线参考转换阶段处理铰链坐标。从规范模型关键帧朝逐关节限位内的候选姿态逐步推进；输出需满足关节限位及肌肉长度范围，并测 LH/RM 基节滚转的双向主动张力余量。若参考不可达，保存结果与偏差。转换所得姿态不用于实时状态回写。
- 环境为既有 125712Z/venv（实际路径 env），MuJoCo 3.9，单线程。源 XML 与保存轨迹的 SHA256 前后核对。训练、优化器和正式行为验收不适用；验收结果见运行输出。
