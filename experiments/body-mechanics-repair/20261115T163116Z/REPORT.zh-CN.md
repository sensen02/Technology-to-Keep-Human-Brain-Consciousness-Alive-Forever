# 双爪足端与肌肉兼容修复首轮

属于人工搭建大脑项目的身体侧力学工作。规范肌肉模型和已验收的 42 路步行模型作为固定对照。颈部与大脑均未接入本轮台架。

| 阶段 | 实测结果 |
|---|---|
| 双爪台架 | 两档积分步长各三组。开口双爪在凸棱上抵住加载，两个步长的最小轴向反力分别为 0.997463、0.997524，加载力为 1。细步长以滑轨广义约束力独立确认反力方向。撤力后抬升完全脱离。去钩尖或去凸棱均滑开，反力为零。 |
| 六足全碰撞首版 | 36 个胶囊段构成 12 个开口爪。平地配对各 20,000 原生步中，首版爪在 20,000 步承载，最大位置分量差 0.0112533，未通过。 |
| 六足粗糙面派生 | 增加显式地形碰撞层。相同平地配对各 20,000 原生步，最大位置分量差 0.0，爪承载步数 0。固定姿态的前左爪与具名工程凸块在注册后出现正法向反力，未注册时该接触不存在。 |
| 肌肉参考转换 | 17/17 姿态回到原关节限位及 90 条肌腱的标称长度范围。左后、右中基节滚转在零速度时的正负主动分量均达到原肌肉关键帧基准，最小约为其 1.017 倍。相对 PD 原姿态仍有 42 关节合计 L2 角差 3.328–3.374 rad。保留根姿态，所得参考未作实时物理写入。 |

足爪尺寸取自三球半径比例，属于未做果蝇标定的工程样件。凸棱是定义明确的机械挂靠对象。光滑玻璃等表面所需的足垫附着应依据独立数据和对照验证。 [果蝇足垫与攀爬原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10119690/)

肌肉参考转换测量了独立肌肉从零到满激活对两关节的主动增量，尚缺逐腿接触下的有效力、被动载荷余额、速度项、可用运动池和时序验证。姿态样本不构成可执行步态，不能用来宣称肌肉已经接管步行。

运行环境为已存在的行走归档 Python 与 MuJoCo 3.9。hook.py、muscle_reference.py 均退出 0。首版 flat_control.py 退出 1，粗糙面派生复跑退出 0，凸块注册探针退出 0。主要运行输入哈希记录在结果文件，正式 XML 前后相同。无训练。

下一步在粗地形场景将新几何计入逐足接触登记与力分解，并使用同一模型做无钩、具名凸棱有钩、无凸棱有钩的真实整蝇对照。肌肉侧优先从兼容姿态做连续、带接触和实际速度的力矩与落足验证，再训练新身体侧策略。
