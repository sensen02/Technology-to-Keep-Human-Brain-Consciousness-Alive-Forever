## 不可混淆的范围

食物坐标、距离、方向不会输入 actor。actor 只接收自身物理感觉和行为网络产生的两个连续命令；行为网络只接收左右局部受体读数及其自身记忆。教师的时间表和目标信息只用于训练数据生成，撤辅后的物理评估不调用教师。

本轮不宣称摄入、饱腹、原连接组能力、生物嗅觉标定或任意扰动稳健性。所有绝对 SI/生物参数仍按项目规则单独标注。
