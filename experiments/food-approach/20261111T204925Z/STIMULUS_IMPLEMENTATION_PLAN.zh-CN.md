## 3. 神经链路和接口适配

环境气味浓度 → 左右两个受体响应 → 行为GRU32 → 转向t → 固定神经ReLU接口 → 运动ANN256状态 → 42个有限PD执行器 → 真实身体 → 新头部位姿 → 新受体读数。

必须修正现有接口差异：旧行为网络输出[0,t]；组合运动模型要求[relu(t)/3,t]。新增版本化接口层，用Torch ReLU与常数缩放构成神经计算图，保留t原值、保留旧权重，不使用按目标位置选择动作的分支或手写步态。左右传感器交换、零输入等只作为显式实验对照。

新完整策略有行为记忆32与运动记忆256，共288个神经状态；受体滤波的2个环境状态另记。复用旧192维身体记录器或旧未训练behavior格式会出错，须新schema和严格加载器。

行为网络仅收到两个局部受体值；运动网络仍收到原238维实际身体输入和2维命令。目标坐标、距离、方位、实验时钟和到达标志仅供环境、训练目标、指标与画面，不进入部署策略。教师参考相位也不进入策略。

每5ms恰好更新一次感觉与神经策略。动作在t使用此前区间已算出的受体响应，当前头部位置的浓度只更新下一次响应；不读未来区间。原1s稳定+4.8s教师预热+9.6s ANN保持，预热期间源关闭、行为状态保持初始，运动网络按真实预热感觉连续积累状态；撤辅、气味出现/消失、感觉切断和方向变化时均不reset。

旧FoodNeuralPolicy、旧evaluate_food不能直接接入：旧接口forward固定0、motor hidden192、behavior checkpoint格式和资格schema都已过时。必须在新目录写适配，不修改旧源码或把strict qualification函数改成总是True。

## 4. 实验准入分层

用户已接受当前转向效果，允许以该基线做刺激研究；不得再把历史数值FAIL包装成PASS。新runner显式绑定用户裁定、同模型SHA和限定experimental模式，同时保留原工程五门的原值与判定。旧严格资格入口保持原样。

新刺激研究的推进依据是：输入身份和因果时序正确、实际神经输出施加一致、身体保持足载支撑/COM/推进、非足接触和额外力为零、六腿周期完成，再看刺激效应。跌倒或非足代偿产生的转角不算刺激响应成功。原滑移与角度阈值始终另列，用户接受不等于严格数值资格。

不得要求弱刺激也转满30°。下面的响应角度是新感觉实验的效应判据，不能据此将旧30°验收改为通过。

## 5. 阶段A：接线及中间命令检查

先不训练任何网络。

1. 零物理检查：权重与source/data SHA、左右符号、2受体输入边界、ReLU命令投影、288状态连续链、5ms时序、source关闭时的因果输出、存取重放。
2. 复用同SHA已完成的直行、全左、全右数据，不重跑已有端点。
3. 新增最多3个完整运动输入探针：+0.5、-0.5，以及左→中性→右的一次连续切换。起始可延迟到撤辅后0.6s以覆盖气味反应启动相位；切换时间实施前冻结，所有状态保留。

这些是高层命令诊断，不计气味刺激成功。它们仍由运动ANN生成42维动作，不播放关节动作序列。

观察方向、瞬态、支撑、接触、六腿周期及原全部滑移分子/分母。进入阶段B的建议功能条件：两个半幅条件相对同窗中性基线分别出现正确方向至少1°的实际航向差，切换能产生对应方向变化；原支撑/COM/推进条件、严格非足零与六腿周期同时满足。原滑移门的分数和FAIL另列，不能将这组功能检查称为原全部运动验收通过。用户对端点视觉接受不自动泛化到半幅与切换。若方向错误或出现新失稳，先定位接口/命令范围问题，再新立有限修复，避免直接进入难以解释的气味失败。

## 6. 阶段B：受控左右气味刺激，首批演示

冻结现有运动和行为权重，先验证组合。首批最多6个完整身体回合：

| 条件 | 要回答的问题 |
|---|---|
| 无气味 | 是否自行产生持续转向偏差 |
| 双侧等强，出现后撤除 | 全局气味强度会不会误触发侧向转向 |
| 左强右弱，出现后撤除 | 左侧输入能否引发左向命令和身体反应 |
| 右强左弱，出现后撤除 | 右侧是否对应右向反应 |
| 左强→右强 | 不重置状态时能否改变响应方向 |
| 右强→左强 | 反向切换能否复现 |

建议统一在撤辅后0.6s出现，普通脉冲3.6s撤除；方向反转条件在4.8s切换并持续到9.6s，浓度上升/撤除按预登记0.2s环境包络，受体滤波和神经记忆仍自然保留。具体时刻实施前冻结。用实验环境控制双侧浓度，强弱水平按既有训练的受体范围校准。浓度钳制条件明确标CONCENTRATION_CLAMP，属于受控刺激实验，不把它当空间导航。源出现/消失控制浓度，受体仍按原动态自然上升/衰减；不得清空网络记忆、设turn死区或按刺激标签直接选运动动作。

建议实施前冻结的功能判据：

- 左/右强刺激有效输入后2s内，高层转向命令符号与刺激方向一致；持续强刺激末段至少9/10合格采样符号正确。合格输入定义和受体幅度阈值写入预登记，不用时间点数量当独立重复。
- 左右条件相对匹配无气味回合的身体航向变化分别达到正确方向至少1°；身体稳定条件同时成立。
- 无气味神经turn RMS≤.02；等强/无气味的额外航向偏差目标≤2°，按匹配基线比较，不要求原本有小幅漂移的身体绝对零角。
- 撤除后1s内，turn返回无气味带附近，后0.5s RMS目标≤.05；这一条仅判断神经转向撤回，不冒称身体已完成减速停车。
- 切换后3s内出现可测的反向身体航向效应；两向均检查，无状态重置。

交付左右各一片全阶段同次视频、一张受体/turn/实际yaw同步曲线、无气味与切断对照。身体视频必须实际打开查看。

## 7. 阶段C：固定空间气味源，开发布局

在阶段B有可解释结果后，释放浓度钳制，改用环境侧固定高斯气味场。每次根据真实头部位姿更新左右采样点，身体动作改变浓度，形成闭环。

最多6个开发回合，建议4个侧向源（左右各两种方位/距离组合）+正前方+无气味。首轮可从方位约±.18/±.28rad、前方距离约.6/.8原生长度、patch半径.06开始设计；这些为提案，实际先按当前头部几何、已归档直行路径和9.6s可达性校验后在任何本轮训练前冻结。工程长度不写成独立标定的SI单位。

目标必须离开无刺激直线路径，不能把目标放在本来就会走过的区域，再把偶然穿过称为趋味。允许用旧无刺激路径设计可辨识布局，但不得查看待测试闭环策略结果后筛选“容易成功”的测试场景。

完整记录：d_start/d_end/d_min、实际头部proxy路径、源距离变化、bearing诊断、累计转角、受体、rawturn/投影后命令、六腿/足载/COM/非足/滑移及分母。比较有气味与匹配无气味/感觉切断。只显示颜色或转向符号还不能称为身体趋近成功。

先不训练。若现模型失败，区分刺激不可辨识、感觉/行为方向偏差、部分命令范围不稳、到达后穿越等问题。确需训练时先只调整行为网络，运动模型保持冻结；新增训练数据与验证布局分开、一次明确有限候选，保存并独立重放。环境bearing/距离可作训练标签或奖励，绝不进入部署输入。暂不默认启动昂贵全身端到端PPO；若以后用PPO，必须先完成既有协议的损失/GAE/优化器检查。

## 8. 阶段D：冻结策略后的留出与因果对照

开发后冻结完整策略SHA，再一次测试8个未用于本轮调参的空间布局，左右各4，覆盖两种角度/距离组合及预登记噪声种子。示例角度±.20/±.30rad、距离.55/.75，具体与训练历史去重并完成可达性检查后冻结。静态预训练可能见过相近浓度，不能冒称所有元素均全新。

建议以几何到达作为首版有界指标：实际头部采样中点进入patch并连续停留至少.2s；8个正常布局至少6个达到。这里是几何接触proxy，不是嘴部动作或摄入。仍完整跑满9.6s，报告是否穿出/过冲；不在到达瞬间停仿真、冻结身体或脚本刹车来制造停驻。

为8个正常布局做匹配无气味、受体切断、左右受体交换，最多32个回合（含正常8个）；可严格证明相同输入/相同种子的对照按身份复用，报告唯一物理回合数，不把复用副本算独立重复。感觉切断至少包含刺激响应已建立后再切断的条件，保留记忆与身体状态。

建议要求正常感觉到达数量比各对照至少多4个布局，并同时比较距离下降与航向变化；若任务本来无感觉也能成功，不能宣称感觉依赖成立。另选2个代表布局做高层命令重放控制：更换场源而重放已保存t，实际运动应保持对应重放轨迹，说明场源通过感觉—神经命令影响身体，而非隐藏物理力。该重放不计新闭环趋近成功。

这批最多34个回合是后期确认预算，不在首批演示前全部启动。留出失败如被用于诊断，今后归为开发历史，新的确认数据另行预登记。

## 9. 本轮不伪造的能力

- 到达后仍向前走，就报告“进入并穿过”；停驻需要后续独立神经减速/停止模块。不能用if距离小于阈值就置零动作冒充神经停驻。
- 几何头部proxy到达不等于吃到；摄入、嘴部控制、饱腹、饥饿状态后续另立。
- 当前LEFT速度与转向耦合，不宣称独立速度调节或任意幅度/任意时长转向已通过。
- 高斯气味、两个头部外工程采样点与C/(K+C)转导是已声明工程模型，不冒称真实触角解剖和生物嗅觉验证。
- 用户视觉接受允许当前实验研究，不把旧工程FAIL写成PASS；所有旧失败保留。
