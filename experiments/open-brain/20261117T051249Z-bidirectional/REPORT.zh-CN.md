# 开源果蝇脑双向颈部接线与身体复验

本轮为研究原型。实现落在开源果蝇脑项目。正式双向台架采用同一只 BANC v888 的来源图，使用冻结的开源 LIF 动力学。另外保留完整 Eon/FlyWire v783 脑的下行接入。所有物理动作使用颈后神经元响应：地面用 FlyGym 身体局部控制器，空气使用 FlyBody 原上游物理与公开冻结飞行策略。实际训练零次。

## 结构和神经台架

52 根轴突通过双截面同一分支、精准根 ID 和发布突触核查，其中下行 27 根，上行 25 根。24 个命名组包含主通道及姿态等补充亚组。固定 BANC 局部模型覆盖 8,395 个细胞、14,689 条颈后或脑侧输出边、603 条身体受体到上行中继的边。完整、全切再恢复和单路切断三组独立复算各个发放时间。最终 52/52 均在完整组诱发相应膜电位响应，切断时丢包，恢复后传递新脉冲。2 ms 是工程传导时间，LIF 参数为冻结先验。对部分递质采用发布预测，几条结构或递质不满足条件的候选保留为未准入。

| 功能 | 接入及检查范围 |
| --- | --- |
| 起步、调速 | DNg100 和 DNg97。扩展版实际发放，颈后物理均复验 |
| 停止 | DNg60、DNg74_a、DNg74_b。三个分支独立神经核验，物理用 DNg74_a |
| 后退 | MDN。BANC 3 根具名实测，另一根缺有效颈部标记。Eon 的两个右侧 BANC MDN 映射同一个 FlyWire ID，跨标本版本仅录入无歧义左路 |
| 转向 | DNa02、DNa01、DNg13。三组做神经核验，DNa02 做常规转弯和站姿转向物理对照 |
| 飞行 | DNp11、DNg02_a、DNp03、DNp10。分别检查中足伸展、翼振幅、双翅不对称、抑制拍翼的工程读出 |
| 上行 | 前足触碰、负载，关节位置、运动、振动，翅根、平衡棒、足端味觉、腹部触觉，以及 BANC 标注的腹部氧合候选 |

Eon 原版 138,639 个细胞的运行中，25 根经同源核对的下行有实测发放，完整通过 255 个脉冲，切断阻断 82 个。右 MDN 无法一对一拼接，双向包含上行的实验采用同 BANC 样本。视觉与触角的嗅觉、听觉属于头侧入口，现有接线从这些感受器所在头侧进入时无需添加颈部中继。本轮未完成头部感知驱动与自由飞行导航。腹部氧合系来源中的推定身份，已做模拟受体脉冲传递，未标定氧浓度到发放的感觉关系。 [BANC](https://pmc.ncbi.nlm.nih.gov/articles/PMC13518251/) · [MDN 原始研究](https://pubmed.ncbi.nlm.nih.gov/24700860/) · [停止回路研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11446846/)

## 实际身体结果

- FlyGym 无附着平地配对中，DNg100 前进 6.06 mm，加入 DNg97 后活动窗前速 5.38→11.33 mm/s。DNg74_a 在保持推进刺激时使足地运动停下，1.15–1.34 s 横向平面净位移约 0.00024 mm。全切下行仍有受力触觉上行，前移约 0.00 mm。MDN 后退 5.35 mm，伴随约 25°偏航。正常左右转约 +40.9°、−45.0°。站姿转向经局部增益调整为 +36.9°、−33.0°，平移 1.29、2.13 mm。这是有漂移的站姿转向台架，尚未过严格原地和步态质量门。
- 地面腿部关节、速度、加速度及实体接触，和空气物理翅驱动力矩、平衡棒铰链速度，分别作为工程感觉代理。前足味觉实验设置均匀试验味源，只在真实前足接触时转导。前足触碰上行单切的两组都在走，物理和姿态逐位一致。442 个前足触碰到达变为 0，测定脑侧 133 个靶点的最小膜电位轨迹，最大组间差 7.52 mV。腹部触觉和氧合目前为神经台架。
- FlyBody 原气动身体的 70 ms 对照中，翼振幅控制通过颈后活动开启翅部执行，空气比零密度与零黏度组在末端多保有 2.01 mm 高度。下行切断实际翅执行力为零。DNp03 使两侧翼命令产生不对称，DNp10 降低拍翼，DNp11 驱动中足伸展。地面自主起飞和主动落地的序列待验。 [FlyGym release](https://github.com/NeLy-EPFL/flygym/releases) · [FlyBody](https://github.com/TuragaLab/flybody)
- 使用 Janelia 发布的冻结飞行策略和 fmech 翼型数据。从同一空中初态自由飞行 280 ms，实际前移 55.8 mm，全程地面采样接触为零。颈后门关闭后翅执行力为零，完全切断 43 ms 触发低高度终止。使颈部中断后实际翅执行关闭 10.8 ms，再恢复，仍飞完 280 ms，最低质心高度 8.84 mm，末端 9.84 mm。另一回合翅执行关闭 42.4 ms，在重新启用前低高度终止。公开策略内的低层轨迹参考只用于这个定向飞行台架，脑的视觉制导、空中真实转向与自主起降仍需验收。 [官方冻结飞行策略、飞行数据和翼型](https://doi.org/10.25378/janelia.25309105)

## 复验和证据

工程源为 `PORTS.json`、`build_catalog.py`、`circuit.py`、`physical.py`、`flight_gate.py` 与 `free_flight.py`。全部实验位于 `/run/media/sensen/Data2/cell_wound_prototype/experiments/open-brain/20261117T051249Z-bidirectional/`。神经 `neural_bench.py` 和 `eon_ports.py` 使用归档 Python 3.12.14、Torch 2.5.1 CPU 单线程。FlyGym 原生物理使用 MuJoCo 3.9.0。公开飞行策略的独立环境用 TensorFlow CPU 2.17.1、TFP 0.24.0、dm-control 1.0.20、MuJoCo 3.1.6。旧 TFP 序列化类型名用兼容别名，保存网络不变。短、长飞行和全切均保留。

原 3 ms 受体刺激两路仅出现一次发放，完整保留 44/46 结果。将独立试验刺激更新为 2.3 ms，全部 46/46 和加腹部的 52/52 通过。首次下载遇重复 GCS 散列头，修正按所有响应头分离 MD5 后校验通过。地面判定代码首轮误将所有接触含自接触计为地面，复跑使用具名 groundplane 接触对。最初 0.18 mV 飞行门无法在短切断内回落，依保存电位改设工程阈值并保留原记录。最初站姿转向右侧仅约 −1°，调整局部增益后两侧重跑。最终 `audit.py` 已对轨迹、输入哈希、神经运输和身体对照复算，`plot_evidence.py` 与 `render_flight_evidence.py` 已生成实际查看的图。
