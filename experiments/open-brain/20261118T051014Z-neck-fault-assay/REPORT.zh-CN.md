# 具名 BANC 颈部轴突的撕裂、漏发与阻断

沿用 P1 开源 Eon 脑、前足感觉编码、固定颈部、VNC 读出与冻结身体的双向平地闭环。每个种子的一条未干预对照和五条故障臂共享同一初始站姿、相位和脑刺激，各自产生自己的足端反馈。每个回合运行 2 秒。

## 仿真中的故障位置

沿用上一轮接触仿真中的三条 BANC 追踪轴突。预设材料裂缝位于接触中心的头尾轴 57 µm 处，从模型壁向内延伸 15 µm。裂缝和左前足 AN 相交，投影深度 6.74 µm。右前足 AN 和右 DNg100 在同一截面深约 37.01 µm 和 67.89 µm。左 AN 根 ID 为 `720575941633589179`，右 DNg100 为 `720575941500851362`。裂缝投影只用于这三条已重建路径，没有推断其余轴突的受损覆盖。解剖来源见 [BANC 原始研究](https://www.nature.com/articles/s41586-026-10735-w)。

从 0.65 秒起，撕裂分支持续切断穿过裂缝的左 AN。左 AN 漏发和完全阻断共用同一个轴突截点，右 DNg100 漏发和完全阻断独立测试。漏发是在 0.65–1.20 秒对经过故障点的每个脉冲施加预设 35% 的独立失败率，完全阻断在同一时间丢弃全部穿过该点的脉冲。两个被干预通道由源侧到故障点均为 0.7 ms，全段延迟均为 1.3 ms。下行在脑发放后再等一拍入段。已经通过故障点的脉冲照常到达，故障结束后恢复新脉冲的传播。所有干预均发生在具名轴突的传导段内。

三个故障是短时工程情景。撕裂分支用已知位置的预制裂缝决定拓扑断连，真实裂纹的生成、延伸、应力变化和组织反应留待具备材料标定后求解。漏发与阻断的强度和持续时间由协议指定。

## 信号确实到达了哪一层

| 施加故障的通道 | 干预窗内丢失 / 尝试 | 1.20 s 后实际传导 |
|---|---:|---|
| 左前足 AN 撕裂 | 144 / 144 | 阻断持续，282 次尝试均未到达 |
| 左前足 AN 漏发 | 42 / 148 | 280 次尝试均到达 |
| 左前足 AN 完全阻断 | 144 / 144 | 285 次尝试均到达，首个到达在 1.2030–1.2263 s |
| 右 DNg100 漏发 | 41 / 102 | 62 次尝试均到达 |
| 右 DNg100 完全阻断 | 111 / 111 | 64 次尝试均到达，首个到达在 1.2057–1.2080 s |

左前足三种工况都先出现颈部到达差，再出现入脑事件、脑部 DN 发放、颈后运动命令和关节状态的差异。以种子 10901 的撕裂为例，各层首次差异依次出现在 656.4、657.6、712.2、736.5 和 737.0 ms。右 DNg100 直接干预先改变颈后到达，随后改变运动命令、关节状态和身体上行反馈。以同种子的完全阻断为例，DNg100 到达、命令、关节和上行到达的首差依次为 661.1、684.5、685.0 和 750.5 ms。

撕裂与左 AN 完全阻断在解除后首个新脉冲到达前，神经信号和身体轨迹逐拍相同。

右 DNg100 完全阻断在三个条件里均造成同方向额外偏航，并在完整 2 秒内把向前净位移减少 2.34–3.58 mm。脑端后续发放也因身体反馈路径而改变。左前足 AN 的效应随种子改变，两个随机漏发回合超过轨迹门。三组都恢复了可逆阻断通道的新脉冲到达，但其中左 AN 有一组、右 DNg100 有三组未回到配对轨迹门内。18 个正式回合全部通过原行进、末段站稳和身体安全门。

三个种子的未干预对照与旧平地完整档案逐值一致，独立逐拍重算了每臂两个 AN 和 17 个 DN 的到达。另跑了 6 个独立重放回合，75 个数组逐值一致。累计 480,000 个身体原生步，优化器更新为 0。

## 对模型适配的含义

先把右 DNg100 的通信中断作为地面闭环的重点故障。当前结果从颈段到达丢失开始，所有身体仍能走并停稳，现阶段不直接重训身体。若后续目标是让受损的平台维持原轨迹，应先找出仍能穿颈且能承载对应命令的通道，再用相同闭环对照检验是否需要训练。左前足结果提示要覆盖多种起始相位和刺激，当前三个条件同时改变这两项，无法拆分各自贡献。

## 真实研究复核后的边界

补充检索没有找到成年果蝇颈轴突束穿刺电极的长期组织学、逐轴突传导和复杂行走联合研究。果蝇急性穿脑电极可在约 20 分钟的基础行走测量中不产生显著差异，果蝇穿透或挤压损伤研究同时证明数小时内会发生细胞死亡、胶质和先天免疫反应。其他昆虫的长期神经电极还会产生血细胞包裹、阻抗漂移、挤压和运动伪迹。因此，本报告的裂缝、35% 漏发和短时阻断继续登记为工程敏感性条件。
