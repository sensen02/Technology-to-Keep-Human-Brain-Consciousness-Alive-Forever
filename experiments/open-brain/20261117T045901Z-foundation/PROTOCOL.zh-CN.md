# 开源脑下行基础台架

P1/P3、S1/S3。冻结 Eon 提交 `a3db62f9436074e485c0278290c2164ed6150808` 的 FlyWire v783 全脑及动力学。采用 BANC v888 左右 DNa02、左右 DNg100 四个具名神经元的跨颈骨架和 v2 官方边表。台架到颈后第一阶神经元为止。两个标本之间使用已核对的神经元同源配对。一个脑侧发放只进入一个 BANC 轴突。所有条件共用原上游权重、同一个随机种子和固定时序。训练更新与身体物理步数均为零。

## 刺激条件

以 0.1 ms 为时间步，共 160 ms。0–20 ms 无输入，20–110 ms 施加固定输入，110–160 ms 撤除。从原公开 `p9` 配置取同一对 DNp09 和 100 Hz 作为脑内推进相关探针。在左右 DNa02 及两根 DNg100 上分别施加同样的 100 Hz，作为具名线路阳性对照。另用源脑中到单侧 DNa02 具有正符号直接突触、且到该侧输入总重大于对侧的 PFL3 细胞各做一组。在无刺激条件检查全链底噪。全部为模拟外部神经刺激，关闭时外部随机输入为零。未经复眼转导，也未推断运动。脑内探针有无诱发具名输出均完整保留。

## 通过门

1. 上游源码和数据与固定提交公开 Git blob 相符。四个 FlyWire 根 ID 在全部索引中可用，类型与侧别匹配。BANC SWC 同祖先分支实际越过 `y=370000` 与 `484000 nm`。目标聚合与源版边表逐边匹配，校核各根及目标并集。
2. 用原版 `TorchModel` 配对复算有输入前缀，并逐步比较神经状态。稀疏 CPU 计算只累加有发放的列，另用原版稀疏运算在非空、正负输入混合条件比较。保留发放时间与快照，不改变连接与模型。
3. 各具名阳性条件均须有实际源端脉冲。正常时用工程假设 2 ms 传导延迟逐脉冲到达，随后按发布突触计数和统一胞外参数进入原 LIF 更新。DNa02 源注释确认 ACh，DNg100 为预测 ACh。该时延以及突触、膜模型的参数缺少本路径生理标定。
4. 在同一保存发放上重放完整、全切再恢复、仅左 DNa02 切断再恢复。切断窗 `[45,80) ms`，切断边界清除途中的对应发放，恢复只传新发放。保存全部源端、颈后到达、第一阶膜电位和脉冲。独立脚本从记录和官方边重算传递时间、邻接输入和神经数值响应。无输入的静息全链保持静息。生理真实性、上行、神经至肌肉与行为另验。
