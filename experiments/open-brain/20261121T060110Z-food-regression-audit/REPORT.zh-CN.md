# P1 替代身体觅食加练回退核对

22 个教师成功回合均从相同的两帧摄像机姿态起步，逐回合固定 226 针分选的下行历史，交叉加载 long-rollout 与 twenty 的动作权重和足压估计器。两次训练的肢段约束、口器偏移文件逐字节一致。验收要求同一拍口器水平距离 ≤4.55 mm、口端高度在 0.02–1.44 mm、至少三足承重且躯干直立系数 ≥0.88。每条回合有一拍合格即计一次。足压置换指更换估计器，按各自生成的姿态实时估算。

新动作单独换上时已失去最早两条；估计器的变化在新动作上进一步拉低新增场景表现。新 / 新在近、中、远三个距离组分别成功 4/6、3/6、2/6。该结果仅用于分组描述，每组六条。在新增 18 条中旧 / 旧离食源中心最近距离的均值为 1.99 mm，新 / 新为 4.33 mm；按每条回合累计接触时间再取均值，由 1.112 s 降至 0.236 s。对外测足压的回放存在预测足尖姿态与原教师足压不配对的问题，只作敏感性对照。

例 88207 的既有记录显示，外测足压下 50 ms 标记误差从 0.176 下降至 0.172 mm，但自估足压的整回合终点误差从 5.16 升至 11.96 mm。原二十条实验同步更新足压 1400 次、动作 3500 次，最长训练展开 500 ms。实验对照支持组件更换导致接触回退，具体是哪些参数或训练项造成漂移还需要独立干预。旧电极闭环三个场景均能摄入但完整任务 0/3，仍有站稳缺口。

建议保留旧动作与旧足压为接近基线。冻结基线先测试餐后局部调整；以视觉、足压和归档摄入时间分段做监督，部署时只允许使用可得并已验证的感知或口器接触。若现有输入无法判别阶段，先核对观测可辨识性。食物坐标及教师状态用于计分和训练监督。候选按完整轨迹的接触、接触持续时间、摄入和餐后站稳逐项与基线配对，另留独立新场景做最终电极闭环验收。
