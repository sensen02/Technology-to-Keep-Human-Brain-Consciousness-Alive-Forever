# 开源脑项目身体首课（P1、S2–S5）

冻结 FlyGym 2.1.0、MuJoCo 3.9.0、标准六足、42 路原位置执行器、无足部附着。所有教师、训练采样和评估从同一序列化站姿开始；神经时钟 0.1 ms，颈部 2 ms 工程假定，原 VNC 探针每 0.5 ms，学生 1 ms 决策。选择已验过的 DNg100/DNg74_a/DNg97 和前足触碰/载荷 AN，按照发布边进行积分，只裁掉无关组。监督目标是 FlyGym 原混合教师同拍的实际执行器目标。学生输入包括 VNC 探针生成的左右读出、关节角速度、当前执行器设定点、接触和身体姿态速度，不含脑侧意图、世界坐标、教师相位、帧号或递归状态。

`cases.py` 预定义整回合分组和脑侧发放时刻。基线拟合使用训练组教师，允许补一轮学生实际偏离时的同态教师标签。身体闭环只用保存再加载的学生权重。所有评估原生连续，不接力、无序列动画。侧推仅声明的 .12 W×20 ms 寿命。

工程验收根据已归档相同 FlyGym 身体在 1.7 秒的走停实测设置。起步前 120 ms 平面最远漂移 ≤ .080 mm。完整行走净推进 ≥ 1.20 mm、指定 0.5 s 前进窗速度 ≥ 2.5 mm/s，每足检测至少两次触地上升和两次离地。胸部高度 ≥ .53 mm、姿态世界向上分量 ≥ .80。停车末 200 ms 平面最远漂移 ≤ .10 mm、速度 RMS ≤ .30 mm/s，切断／静立回合同时要求实际颈后驱动为零（允许受验证的旧膜电位衰减），同时间窗的净位移 ≤ .16 mm。带恢复回合还要求恢复后推进，未恢复前无推进读出。指标是该 FlyGym 身体的研究工程门。原项目 D1–D8、滑移与肌肉制备验证另有约束，不以工程门覆盖。

BC 固定 40 个 epoch，每个完整 epoch 作为一次可复现记录，保存权重、Adam 与生成器状态。DD 同口径最多追加两轮。完整留出含不同发放时刻、DNg74_a 主动停、瞬时下行中断恢复和声明侧推。指标和失败日志保留，原始教师与历史人工脑结果分开。
