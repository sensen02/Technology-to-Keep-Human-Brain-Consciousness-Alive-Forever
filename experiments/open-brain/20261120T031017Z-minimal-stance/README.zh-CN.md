# 果蝇原始连接组与肌肉身体的最底层基线

手动研究基线。目标是查清站立的身体条件和连接缺口。最小包提供两个独立入口。身体只运行原 MuJoCo 肌肉模型，神经只运行原 BANC 电导点模型。两者之间暂未接在线感觉、肌肉转换或动作控制。运动池映射仅供检查。包内没有翻译层、训练权重、ANN、CPG、PD、动作表或姿态保持器。

## 身体和肌肉

规范模型同时包含头、胸、腹、翅和六腿。直接用 MuJoCo 3.9 编译得到 71 个网格、一个自由躯干、42 个腿部铰链、90 条肌腱和 90 路原生肌肉。规范 XML 保持归档字节。90 路的原生控制下限均为 0.0001，另在内存中清零做成单独对照。

起始质心约 1.86 mm。原关键帧左后基节俯仰超出声明范围，历史六足姿态的 42 个铰链均在范围内。两姿态分别对 90 条肌肉做 20 ms 单路激活台架。全部有主动拉力增量，长度均在 XML 声明的工作域，42 个关节都测到两向主动轴力矩。肌腱力矩臂有限差分最大误差 3.19e-10 mm/rad。逐肌肉拉力单位保留为模型原生单位。

静力补充使用同一姿态和原生摩擦约束行，仅开放脚—地和内部原生约束反力。允许 90 路各自出力时，两姿态全自由度平衡的最小最大归一化失配为 2.60% 和 2.56%；限至有候选运动池的 74 路后为 3.33% 和 3.67%。求解只针对这两个姿态。布置新的姿态或建立动态稳定所需的肌肉策略仍是独立问题。 [FlyMimic 前腿来源](https://gizemozd.github.io/fly_mimic/)

## 神经与肌肉接线

- 冻结的旧 BANC 子网有 12,000 个细胞和 291,986 条建模有向边。缓存切入子网原有 442,843 个有向对；按历史递质规则略去 150,857 对，其中 150,298 对源细胞缺标签。边指纹 `5ab78f550d682e2849749587cb6f7551`，与早期快照独立重建一致。神经元参数与统一 2 ms 延迟属于工程模型。
- 编译后的 90 路肌肉逐条核对来源表的肌肉目标、腿位、侧别和根 ID。65 路完整保留所声明候选池，9 路部分保留，16 路未解析。八对肌肉共用来源运动池。208 个声明来源根 ID 中，两枚旧根在本次图缓存及元数据的 `banc_888_id` 精确匹配中缺席，仍保留旧来源行。相同腿位目标与同名肌束的一对一支配关系仍待验证。
- 74 路有池的肌肉均能从本腿机械感觉群及下行群找到有向图路径。独立零输入保持静默。逐腿以人设电流刺激整个机械感觉群时，单次有 71–72 路候选池发放。直接刺激原缓存注释为 DNp10 的一个下行细胞时，68 路候选池发放。至少一次发放覆盖了全部 74 路有池肌肉。所测是非生理台架刺激下的可招募性，尚无自然感觉转导、逐肌束神经肌肉接头、过颈时空传导或站立闭环验收。

## 独立运行

在包目录里使用 Python 3.12、MuJoCo 3.9.0、NumPy 2.5.3 和 SciPy 1.18.1。只运行身体时无需 SciPy；只运行神经时无需 MuJoCo。无需 FlyGym、外部数据缓存或网络。

```sh
sha256sum -c ASSETS.sha256
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B run_body.py body_results
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B run_neural.py neural_results
```

`body/` 含规范 XML、71 个网格和同模型的历史六足姿态。`banc_tier.npz` 含原图两个有符号稀疏矩阵与根 ID，`NEURAL_INPUT.json` 固定诊断刺激。连接组来源为 Bates 等的 [BANC 数据](https://doi.org/10.7910/DVN/7WTH1N)。肌肉身体由项目基于 [FlyMimic](https://github.com/gizemozd/FlyMimic) 派生，STL 来自 FlyGym 本地 `neuromechfly_musculoskeletal_meshes_20260623a` 资产缓存。

完整检查和证据保存在项目实验目录 `/run/media/sensen/Data2/cell_wound_prototype/experiments/open-brain/20261120T031017Z-minimal-stance`。覆盖审计的细胞及肌肉逐项证据见 `results/MUSCLE_CHAIN.json` 和 `results/WIRING.json`。物理、神经、静力共 92 份保存数组在第二进程逐值一致。训练更新为零。现有档案与工作区已有修改留在原位。
