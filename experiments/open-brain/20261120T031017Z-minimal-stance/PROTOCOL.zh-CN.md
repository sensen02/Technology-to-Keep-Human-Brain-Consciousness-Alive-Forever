# 原始连接组项目的最底层站立诊断

P1、P3，S1–S5。固定旧 BANC 12,000 细胞默认选图及规范 90 肌肉模型。使用同一 XML 的原关键帧及旧归档同 XML 的合法六足姿态。身体与神经运行器分开，接线只生成证据。零训练。物理用 CPU、MuJoCo 3.9，神经用 CPU、原电导点模型。时间、输入及产物由同目录源码和清单锁定。

- 正式身体对照保留原 XML，仅写入一次起始姿态，随后 `ctrl=0`、无外力。两个姿态各另跑肌肉控制下限临时清零对照，编译模型内存变动独立登记。每条 200 ms，原生 0.1 ms，保存足地法向、非足法向、三足承载、整体质心、位置速度、肌肉激活。站立诊断门在最后 100 ms 逐拍要求至少三足分别承担 >0.01W、足总载在 [0.8,1.2]W、非足正法向为零、质心高度 ≥ 起始 90%、身体保持直立（胸节竖直轴余弦 ≥0.95）。这是短时零命令站稳指示，原 D1–D8 仍适用各自正式实验。初态关节范围与接触实测另报，未进行寻优或重新摆放。
- 同两姿态用冻结状态 `mj_forward` 检查 90 路肌肉、长度范围、力矩臂、主动/被动力。在零下限诊断模型对每路原生肌肉独立施加 20 ms 单位命令，在 MuJoCo 的 actuation 前向子阶段积分激活而保持姿态固定，用作接口诊断。核对关节轴力矩来自该肌肉的原生传动。有限差分检验 `moment = d(length)/dq`；编译名称与运动池逐个绑定。
- 神经结构按原始缓存、原子网的无符号边、建模有符号边三个层级核查。以本腿感觉根及颈部下降群为起点记录每个运动池最短有向路。检查逐执行器来源根、腿侧、团体复用、是否被裁剪、是否在实验探针发放。结构可达性只作候选证据。脑颈结构按来源注释，均一 2 ms 延迟属于神经数值模型。
- 神经探针每条 120 ms、0.5 ms，独立零输入，以及六条腿分别向已选机械感觉群直接注入恒定诊断电流（0.08 nA，10–40 ms）。输入是人为台架刺激。另做单个存在出边的注释下行神经元探针。记录输入群、全部尖峰、最终膜电位。第二进程以相同输入重跑完整身体与神经数组。正式入口无外置翻译、ANN、PD、CPG、时钟动作、状态覆盖或神经到物理的连接。
- 体表、肢体和消化相关覆盖分别按本地数据标签、子网保留、建模边、运行接口报告。无源映射保留为空。仓库原始身体、神经和历史产物保持原位。本轮交付可独立重放的研究基线和失败诊断。

## 固定姿态静力补充诊断（求解前登记）

在上述两份同一初态、零速度下各做三次静力松弛，分别允许全部 90 路肌肉独立激活、仅 74 路有池肌肉独立激活、对共享池施加同一激活（66 变量）。用 0 和 1 激活取得全量程下的原生肌肉力，确定仿射关系。只允许现有脚—地接触行、现有内部约束反力及现有肌肉；其他地面接触禁用。采用原生摩擦锥的求解器雅可比，先逐项核对 `J.T @ efc_force`。对全 48 自由度最小化最大绝对失配，身体重量和体重×1 mm 分别归一化平动与转动残差。残差≤1e-8 原生单位才有平衡证据。静力松弛让接触和限位反力独立取值，结果不证明软接触动态站稳或该姿态之外的不可能性。所有激活和力仅求解与记录，未向物理积分回放。
