# 身体上行反馈触发主动停餐

两组独立种子通过原地摄食闭环。完好组在约六成充盈时主动关闭进食。在相同糖味、同初始身体与同站姿接触下，切断上行后持续进食。恢复上行后重新出现主动停餐，食物仍可及、嗉囊仍有空间。

| 条件 | 种子 4339 | 种子 7213 |
| --- | ---: | ---: |
| 完好组首次主动停餐 | 300 ms | 280 ms |
| 完好组停餐时嗉囊充盈 | 59.64% | 59.13% |
| 完好组首次连续关停 | 670 ms，随后再开吃 | 持续至观察终点 |
| 恢复组首次到达 | 622.0 ms | 625.8 ms |
| 恢复组主动停餐 | 720 ms | 740 ms |
| 恢复组停餐时嗉囊充盈 | 70.35% | 70.86% |
| 整段摄入，完好／切断／恢复 | 0.161／0.403／0.231 | 0.077／0.403／0.238 |

低充盈组在这两次 1.2 秒回合中均保持进食，摄入与对应切断组逐值一致。恢复组两次都停至观察终点。完好组 4339 在约 0.97 秒复食，这次短窗观察只覆盖体积反馈，营养饱足和跨多餐复食需要独立验收。

## 实际闭环

脑侧糖味沿上轮固定的原生感受器索引输入。身体嗉囊牵张按 0.45 至 0.72 的工程区间募集第 4 组 StN／PhN 十个候选轴突，并经 1.5 ms 的离散固定延迟到达。冻结的 Eon 对收到的候选输入及共同糖味进行积分，双侧 MN9 活动提供开启进食的条件。脑侧的工程适配从上述候选已经发出的脑端脉冲、到 24 个实际脑内受体的原图连接取首级输入分量。读出用突触权重绝对值归一加权并按 130 ms 过滤，在 0.58／0.42 两个阈值切换。Eon 本身仍使用有符号原图持续积分。适配层能按来源单独观测该输入分量，属于有意提供的工程可观测性。它接到已经通过台架验证的单动作进食，实际摄入反过来更新身体牵张。持续接触取自规范站姿口器的真实 MuJoCo 轨迹，本轮该轨迹独立重放一致；脑和身体营养模型在闭环试验中在线积分。

恢复组启用前与切断组逐拍相同。切断组身体发放仍在继续，传导事件全被丢弃。恢复组只接收接通后新发的事件。切断组冻结脑内仍可能因自身反馈招募候选细胞，末梢自发或脑内招募基线保留，两个种子的工程读出峰值约 0.30，低于关停阈值。所有摄入、脑端来源、传导事件、首级输入和动作均分别记录。关停时食物余量超过初始的 88%。四次关停中，最初 100 ms 的每一拍均可摄入，MN9 亦仍有足够的进食驱动，实际摄入均为零。

## 剂量、形态和限制

四剂量试验以 0、0.25、0.55、0.80 初始充盈测试，冻结 Eon 只记录脑端状态。两组训练样本共 232 条，对 24 路下游自然发放拟合了一次岭回归。种子 881 留出平均绝对误差为 0.167，0.25 与 0.55 剂量的平均估计近乎重合。首版自然发放读出只在一组通过完整门，平滑版两组各有失败，包括低充盈误停和恢复后停得太短。失败保留。最终合格项属于首级工程读出，岭回归仅保留作诊断。

第 4 组有十个已发表的 FAFB 候选，两个 FAFB 端点在 BANC 中对应七个候选碎片。七份官方 SWC 均以原对象代数和校验和归档，在旧 BANC 脑—VNC 连接体的两个登记截面上没有命中。本地可见形态用于脑端来源复核，嗉囊至脑的单根完整形态与 Piezo 身份仍未验证。原脑连接表可复核到 15 个按项目阈值筛出的 PhN 脑运动神经元靶点，功能文献独立报告组 4 的咽泵相关投射。本次资格适用于已登记 StN／PhN 候选与工程读出，不能凭候选的短时行为通过指定现实的单根饱胀轴突。
