# BANC 腿部传入增补与动态阈值对照

手动研究版本。增补已接入可独立运行的神经图。身体、在线感觉转导、神经肌肉接口及其他跨颈实现未纳入本次运行。固定阈值和动态阈值均可在旧图或新图上选择，默认运行新图的固定阈值。

## 真实来源的腿部线路

- 保留旧版 12,000 个根的顺序和全部 291,986 条原建模边。所有根都按相同数字 ID 命中 BANC v888 元数据。新图有 12,617 个节点，其中 17 个是此前没有的候选传入根、600 个是此前没有的 VNC 靶点。
- 334 个候选中 114 个既有位置、外周神经和校订记录，也有已验证的乙酰胆碱标签。恢复 **6,677 条**同标本原始连接，其中 **466 条**到有腿部靶标注释的运动细胞，另有 3,456 条在旧图中已存在。所有新增源、靶和原始突触计数均单独复核。220 个候选缺已验证递质，本轮保留原有活动配置，补充的出边暂未启用。原数据中自环、涉及脑／上下行靶点、其他非准入靶点及重复边均单列。
- 选择左右各一条钟形感器边和毛板边作切断对照。四个源在 14.5 ms 首发，目标在 17.0 ms 首次出现差异。2 ms 为声明的工程传导延迟，另有 0.5 ms 积分区间。四条边在首个到达区间均使目标膜电位增加约 1.548 mV，与原生电导更新核对一致。这个结果验证了所选新边的实际接入及方向。目标活动仍受其他网络路径影响。
- 新边按 0.0005 µS/突触记录使用历史工程比例，与固定 2 ms 延迟一并登记。对新增靶点保留本次源图查到的入边，未建完整局部出边。BANC 从外周受体进入中央样本的投射标签不等同于完整周边形态、接触力换算或神经肌肉接头。 [BANC 论文](https://doi.org/10.1038/s41586-026-10735-w) · [BANC 数据](https://doi.org/10.7910/DVN/7WTH1N)

## 动态阈值的实际表现

保留原电导发放模型的膜重置、适应电流和不应期。可选的阈值历史有两项指数，每次发放分别加 1.5、2.0 mV，时间常数 10、200 ms。幅值用于台架，未对果蝇细胞拟合。这是带 MAT 式阈值的原电导模型，仍有膜重置。原始 MAT 的膜积分形式另有定义。 [MAT 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2722979/) · [果蝇嗅觉投射神经元](https://doi.org/10.1016/j.biosystems.2022.104802)

- 旧固定阈值模型的 8 个已保存 BANC 回合重跑全部逐值一致。阈值增幅为零时单细胞与固定版逐拍一致。按实际尖峰逐项求指数核，最大误差约 1.41e-13 mV；独立检查了逐细胞阈值幅值和禁止更新细胞的历史冻结。
- 同一个单细胞从静息接受 45 pA 阶跃，两个模型都在模拟 28.5 ms 首发。固定阈值产生 20 个尖峰，动态阈值产生 13 个。阈值仅由先前的尖峰累积，所以相同初态和参数下的冷启动第一发保持一致。后续放电变化只显示机制已生效。
- 在作者登记的快、中、慢细胞中，找到可供对照的 `CurrentStep2T` 档案和公开分析脚本。Dryad API 对所选 8 个细胞归档均返回 HTTP 401，公开网页的实际文件端点均返回 HTTP 403。Zenodo 已核原发布校验值的附件是分析脚本、说明与表格，未取得原始电流／膜电位试次。现有图像和摘要未用于训练或宣判模型胜负。 [腿部运动神经元论文](https://doi.org/10.7554/eLife.56754) · [原始数据索引](https://doi.org/10.5061/dryad.76hdr7stb) · [作者分析附件](https://doi.org/10.5281/zenodo.4527659)

取得数据后，先按个体隔离校准与留出，分别记录冷启动首发命中与延迟、后续尖峰匹配误差、ISI、持续刺激早段与晚段放电率。两版共用同一输入电流和同一套基础参数。动态增量仅在训练个体拟合，冷启动和既有发放历史分别评分。快、中、慢招募顺序用可比刺激另验。预选细胞、下载状态与哈希记录见 `DATA_ACCESS.json`。

## 使用与复验

Python 3.12，NumPy 2.5.3，SciPy 1.18.1。解压后可脱离工作区和网络运行。`NETWORK.npz` 保留原矩阵与新增稀疏块，`GRAPH.json` 含出处、准入规则结果、334 个来源根和四个对照。输出目录应当是新目录。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B run_neural.py fixed --graph augmented --threshold fixed
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B run_neural.py adaptive --graph augmented --threshold adaptive
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B run_neural.py legacy --graph legacy --threshold fixed
```

来源边复核、第二进程 64 数组逐值比较、已有导纳模型 8 项数值自检通过。零身体物理步、零训练更新。台架图已实际打开。完整研究证据目录为 `/run/media/sensen/Data2/cell_wound_prototype/experiments/open-brain/20261120T034137Z-sensory-graph-threshold`。
