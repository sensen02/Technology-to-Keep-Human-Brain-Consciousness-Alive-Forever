# P1 觅食奖励修复与长训

本轮保持 Eon、固定 BANC、FlyBody 与食物库存接口。两个对照从上一轮相同的冻结脑 SAC 权重起步，均完成180000代理决策、89251次实际更新。联合训练投入为360000决策、178502更新。

## 奖励改变

旧版把靠近食物的路径距离用于每步进展。当身体未横移到安全侧时，这个分数也可能鼓励它往沟沿走。将上一轮六条闭环跌落记录按160ms取样，筛出11个仍缺安全余量且向前的窗口。旧进展分11/11为正，均值+0.069，新版3/11为正，均值−0.190。

桥前2.4mm内先给横移到位和有支撑的进展计分。脚展目标余量1.12mm，未达余量仍前移有独立扣分。对失败的终止状态停发进度收益，跌倒代价−14。只奖励一次满足条件的跨越，继续实际摄入，吃够一餐并站稳可拿到完整奖励。代理姿态门以停止速度和持续接触替代真实多足物理验证，真实试验仍采用食物库存、四足接触、末140ms姿态和速度。严格对照额外取消缺安全支撑却进入代理食区的实际进食分。奖励算例核验减速对齐、贸进、跌倒、重复过桥、零库存和截断。

## 实际闭环

保持上一轮已通过的平地进食收稳逻辑。宽桥以15121重做上一轮失败的左右镜像，15671作新几何镜像。成功门同时要求实际摄入至少0.18、无翻倒、最后140ms至少四足接触且姿态与速度达标。

| 回合 | 支撑过桥 | 实际摄入 | 翻倒 | 完整觅食 |
|---|---:|---:|---:|---:|
| 15121 左镜像重测 | 否 | 0 | 是 | 否 |
| 15121 右镜像重测 | 否 | 0 | 是 | 否 |
| 15671 左镜像留出 | 是 | 0.16240 | 否 | 否 |
| 15671 右镜像留出 | 是 | 0.18165 | 否 | 是 |
| 15107 平地回归 | — | 0.18305 | 否 | 是 |

5.2秒上限下，四组宽桥总支持穿越2/4、稳定完整觅食1/4。真正完成的右侧在2.100秒跨过、2.530秒开始摄入、4.852秒达进食阈值，在5.060秒收稳结束。此前失败的两个镜像没有恢复，两个到沟沿前的支撑边界差分别缺0.81mm和0.67mm。实际速度在到沟沿前的160ms平均为6.82和8.30mm/s。相较上次同一地形与起点，到沟沿时的横移没有一致改善。

所有正式回合均重新核对17路下行时序、真实前足输入、姿态、库存及零额外外力。正式五组共336400物理步、168200脑拍。训练目标允许拍点上的执行余量，现实任务仍需按跑过的场地、种子和固定时限审查，四例为小样本。

## 单例延长和同条件旧策略对照

15671左镜像是正式5.2秒试验中已跨桥、摄入0.16240的一例。上限单独延至7.2秒，前5.2秒的实际身体、视觉观察、食物日志、Eon发放、BANC到达、上行和颈后读出逐值重放一致。延长后累计摄入0.18620，在5.514秒达一餐，最后站稳并于5.760秒结束。

旧权重以同一站姿、双眼、地形、BANC、身体和7.2秒上限重跑该左镜像，2.165秒跌落，摄入0。支持在这一场地上改进了实际行为。延长和旧权重配对不进入正式4例成功率。两种时限与所有失败分开归档。正式与补充共495200原生物理步、247600脑拍。

当前保留中段权重作为实验候选。下一最小动作是固定宽桥课程继续覆盖先前两个失败镜像，在实际前进速度仍高的入沿段训练提前横移；完整候选通过后再判更难环境。
