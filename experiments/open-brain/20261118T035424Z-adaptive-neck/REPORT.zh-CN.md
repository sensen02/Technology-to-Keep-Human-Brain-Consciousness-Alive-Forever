# P1 动态颈部、感觉校正与飞行底座

本目录属于开源果蝇脑分支的手动研究原型。将三件事分开验收：真实来源颈部内的传播参数能否在仿真中改变，脑侧译码器能否在线补偿缓变读数，以及原有飞行底座能否在这个工作树复现。

## 接口安排

身体/感觉器 → 有源身份的 BANC 颈部通路 → 脑侧只读实际到达 → Eon。只有此链路中的实际到达能作为已过颈信号。翻译层额外计算预测及校正建议，独立记录原始值、行为预测、协同感觉预测、估计增益、可用状态和残差。未来要接入脑，应并排保存原始和候选输入，并先用同一场景证明控制不会抹掉真实扰动。已知断路不给出校正值，预测仍可作为辅助读数。

“行为预测”当前只用 Eon 过去的17路运动下行发放作为动作副本；另一线索用对侧实际过颈的前足上行。两种线索也分别拟合，与融合同时比较。没有读取未来或目标自身作为预测特征，没有把位置、受体答案或身体关节观测绕接到脑。连续性核验用模拟器的真实门控日志。如果将来只有原始信号及预测，静默、真实接触变化和传导减少之间可能不可辨认，应输出不确定状态。

当前动态颈部只允许在某一已登记 BANC 轴突上、按发放时的参数调度到达。在途脉冲保留原到达时刻。阻断仍取消该轴突在途信号，其他端口继续传。下一版如果做内生可塑性，应限定在有来源的已知边，先单独验证可解释、可撤销的突触电导强度变化，并审计何时激活、冻结或恢复。BANC 身份、边和符号不随优化器自由变化。生理上真实的变化范围和更新规律尚未知。

## 实际结果

动态传导使用 11701 保存的真实前足受体驱动和两个已具名的反馈 DN，在 BANC 两 AN 加两 DN 子图中开环重放。对照双 AN 发放和过颈到达与完整旧记录精确。左轴突基准延迟 1.3 ms，时变段最长 1.8 ms，实际改变 78 个左脉冲的到达；对侧及两 DN 到达逐值一致。所有到达都可用源发放、当拍延迟及门控独立复算。暂时阻断时左到达为零，开放后新到达来自开放后发放。接线与旧 BANC 结构一致；时间扰动为仿真参数扫描。

读数校正用 10901、11311 共40000帧训练三组岭回归，11701 从未进入拟合。独立留出看到下表。这里只合成目标脑侧读数的乘性漂移，保持实际脉冲时间和左侧真值仅用于对照。漂移段未给译码器真实增益。

| 项目 | 留出结果 |
| --- | ---: |
| 仅运动预测 RMSE | 35.31 Hz |
| 仅另一侧触觉预测 RMSE | 37.04 Hz |
| 两线索融合预测 RMSE | 31.15 Hz |
| 漂移平台期读数 RMSE | 31.70 → 22.25 Hz |
| 健康条件额外校正误差 | 0.51 Hz |
| 短暂 +65 Hz 合成瞬变的增量误差 | 0.22 Hz |
| 漂移退去后的残留校正误差 | 5.68 Hz |

明确阻断窗内，原始滤波尾迹可见，校正值为空，更新暂停。缓变漂移的部分补偿与合成瞬变的保留说明这个设计值得继续。增益补偿仍有迟滞和剩余误差。两线索冲突时当前只保证停止漂移更新，历史增益可能暂时仍影响建议值；接入脑之前应明确冲突时旁路或回退规则，并用未参与训练的真实触碰、打滑和不对称支撑数据挑战。当前结果也没有证明它能校正真实传导延迟、辨认无诊断的断路或还原单脉冲相位。这一版本的塑性是翻译层在线状态；颈部已实现外部受控时变，不含学习出来的生理突触可塑性。

## 飞行推进顺序

FlyGym 2.1.0 的 FlyBody 身体接口有六个翼自由度。短时空中动力学验证使用独立上游 FlyBody 的冻结策略、翼型数据和原颈后使能门，保留与行走不同的动力学资产。可查 https://neuromechfly.org/2.1.0/api_reference/flygym/compose/fly/__init__/ 和 https://github.com/TuragaLab/flybody 。

本轮已经复跑完整和短时恢复两条原生飞行回合。两条均在空中初始化、飞行280 ms、前进约55.8 mm，采样地面接触为零。各5600原生步，身体状态与历史逐值一致。数据和八根真实来源飞行 DN 几何、端口、原脑同源身份在 FLIGHT_AUDIT.json。以前的短时使能门证明的是该身体和已冻结飞行策略的局部能力。

飞行下一最小步是同一空中初态下，让 DNg02_a 实际经过本版颈部后进入两侧翼幅读出，先证明双侧同增量与单侧改变的因果响应。然后用 DNp03 测左右转向，分别验偏航和最低高度；接着用 DNp11 与 DNp10 分开验地面起飞与触地减速、停止翼拍。空中所需的姿态反馈通道另行从源核对，绝不凭已通过的前足触觉模型补出。最终才检验自适应翻译是否提高真实飞行任务表现。

## 复验和路径

DYNAMIC 与 DYNAMIC_REPLAY 四个数组逐值一致；OBSERVER 与 OBSERVER_REPLAY 46个数组含缺失位置一致，拟合文件同字节。最终两次时变台架各20000批/60000 lane tick，两个校正流程各三次岭回归和80000逐帧读数；两条本轮重跑飞行共11200物理步。历史前足/行走/地形已验闭环的资产继续作为基线。首次准备运行保留在 DYNAMIC_INITIAL 与 OBSERVER_INITIAL；受控重跑修订了文件归档及样本计数字段，科学输出逐值一致。新实验代码位于本工作树，旧大量原始数据按 SHA 从主工作区只读引用。不是成品或实体测量。
