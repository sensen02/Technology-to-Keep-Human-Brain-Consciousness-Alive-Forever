# P1 · 饱足下降组在远地果边缘失稳

失稳发生在近果转向和支撑交接。果蝇跟踪到了第二颗地果，营养驱动开启状态贯穿失稳期。左前爪已落在果面时，身体仍在沿原方向转，右前爪只碰到侧壁，未在果面形成同类支撑。之后实际姿态快速横滚，失去足部支撑，头和右中腿胫节碰地。限角和限速反事实只检验这一段身体执行，自主政策保持原设置。

## 发生顺序

| 模拟时间 | 身体与信号 |
|---|---|
| 4.64035 s | 左前爪接触果面，法向几乎竖直。 |
| 4.660 s | 视觉追踪给出的目标已从右转到左，滤后身体仍在向旧方向转。 |
| 4.70260 s | 右前爪首次碰到近侧果壁，法向几乎水平。原记录到首摔前右前爪在这颗果上只有侧壁接触。 |
| 4.720 s | 口器距果心水平 5.72 mm，进食要求 5.25 mm，仍差约 0.47 mm。此时没有口器糖接触，靠糖触发的停步不会启动。 |
| 4.740–4.760 s | 胸部横滚从约 8.5°升到 24.6°。旧方向的滤后偏航要到 4.790 s 才过零。 |
| 4.840–4.841 s | 横滚到约 100°。右中腿胫节先撞地，头部约 0.25 ms 后碰地。 |

第一段出现支撑退化时，滤后推进约 0.492 cm/s，仍在近果降速范围。4.760秒后才出现画面估计距离变大及随后推进回升，时序落在最初倾斜之后。成功的低饱足对照两前爪先后踩到上表面，进入口器接触前偏航已接近零。口器进有效取食范围后启动停步并摄入。

事后重渲染确认在 4.66 与 4.72 秒捕获的候选框中，第二颗地果约占 88% 与 89%。图像和轨迹对齐仅用原运行保存位姿，几何分割不作为原模型输入。

原始左前爪的果面接触在 4.7315 秒之前结束，右前爪的侧壁接触继续到 4.7637 秒。先是上表面支撑丢失，随后横滚增大并触地。

## 单项干预回放

| 只改身体输入，回放到 5.26 s | 首次非足碰撞 | 结果 |
|---|---:|---|
| 原下降组 | 4.84015 s | 翻倒，口器无有效接触 |
| 4.420 s 起限偏航 | 4.91400 s | 推迟约74 ms，仍翻倒 |
| 4.660 s 起取消偏航 | 5.11335 s | 推迟约273 ms，短暂触到食物后仍翻倒 |
| 4.420 s 起推进封顶 0.492 cm/s | 无 | 最大横滚5.08°，口器进入有效取食范围累计105.25 ms |
| 4.760 s 已倾斜时才使用同一推进上限 | 4.84450 s | 延迟约4.35 ms，仍翻倒 |

提前封顶在进入果缘前对原本接近0.533 cm/s的推进只做了较小削减，但改变了落脚与后续口器接触。只收转向提供了额外稳定时间，仍不能在这段回放内维持支撑。已倾斜后才封顶，第一摔几乎原样发生。综合证据指向**身体在果沿由走向停的时序配合**。当前近果减速只看视觉框和估计距离，完整停止要等口器有效接触。两前爪支撑不对称时，这套规则在接触前缺乏对应的推进和转向限制。

两参考回合前缀的原生轨迹及保存位姿逐值一致。四个干预在各自开始前与原轨迹逐值一致，无额外外力。干预后身体与接触动起来，但视觉和神经命令来自原回合，提前封顶出现的口器接触不代表新闭环已经摄入。此次只建立这次跌倒的来源和作用顺序。
