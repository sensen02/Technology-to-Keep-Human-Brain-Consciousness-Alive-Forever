# 开源脑上行翻译与经颈下行训练方案（P1、S1/S3/S4/S5）

状态DESIGN_ONLY。用户将身体阶段性收口，飞行继续暂缓，本轮仅讨论方案，无新增神经/物理积分或优化器更新。身体冻结5e513...ff57e及其70body/48路模型，固定颈部动力学和读出保留；P2人工脑项目不混入。既有身体/刺激范围、速度航向/胸高残差、持续大角度转向限制继续成立。

## 核查事实与先决缺口

本地Eon以138639细胞/15091983聚合连接运行。brain_events.RingBrain保存真实状态及发放，但历史主要刺激指定DN或PFL3并回放；不是已完成上行驱动决策。旧Overlap.decode只使用DNg97/DNa01/DNa02六读出、输出裁为[0,1]，不能直接承担九组地面指令。

CATALOG总52项：27 DN、11 AN、14 SA。历史“25上行”包括AN与SA，不能全部叫AN。11 AN中9项有fafb_match候选，候选不等于同源/侧别/脑内目标核对通过。25 DN获得已审核唯一FlyWire绑定；其中地面17根，八双侧组16根＋MDN左1根。两个右MDN因共享同一FlyWire身份被排除，不能复制一个发放假装两条独立真连接。

FrozenCPUBrain.recurrent_volley使用numpy并硬阈值发放，历史入口还有inference_mode；现有实现不提供可直接反传的完整计算图。冻结参数不等于输入可微，不承诺端到端梯度天然成立。

## 推荐架构

身体真实物理感觉 → 已声明受体转导 → BANC身体侧神经/AN或SA → 真实来源颈部轴突及固定动力学 → 颈部脑侧到达/真实靶点状态 → 有界上行翻译Uθ → 已核对Eon感觉入口/脑内接收群 → 冻结原脑 → 原脑真实DN发放 → 经审核同源身份绑定BANC DN → 同一真实来源颈部 → 已校对固定VNC读出 → 冻结身体。

第一版只训练Uθ。入脑位置白名单由来源决定，排除DN和动作读出，不能把“左触碰”直接改写成DNa02/DNg60强电流。下行不另训练任意选动作的ANN；先将旧Overlap替换/统一为已校对全地面固定接收接口，保持DN身份与原始事件，允许已验反向和制动值，不沿用旧非负裁剪。body和neck不参与训练。

有可靠AN同源绑定时，优先将颈后到达作为对应Eon感觉源的边界事件，经其真实脑内输出边进入网络；必须明确单一边界所有权，不能同一AN先在BANC完整放电、再把它当新细胞重复加一套膜动力学或重复计入突触。若采用电流/速率再编码，额外延迟/发放变换须明确为工程转导并验收。

没有精确对应时，可研究向有限、来源支持的Eon感觉接收群映射，但标为跨样本工程适配，不把学习权重称为真实解剖连接；无法确认接收群则先暂缓该通道。视觉、嗅觉等头部来源按解剖直入头侧，不虚构穿颈路径。

Uθ输入只有已过颈信号及声明的信号时间状态；不含身体原始旁路/场景标签/目标动作/未来状态。先用逐通道基线、增益、饱和和短时滤波等几十个自由度；必要时小型掩码前馈网。允许用于编码的因果滤波状态，不将GRU外置策略藏在翻译层；任务记忆归脑侧研究。

## 分阶段训练

0. 来源与实时接口：先审核前足触觉两路的候选FlyWire身份、侧别、原脑索引、对应脑内边及延迟时钟；再加入负载。共同原生时钟按现有实现走，身体控制1ms，跨模块不能读取未来/重复反馈；闭环最终实时积分双向脑与颈部，不用离线命令回放冒充自主闭环。

1. 纯感觉辨识：同一原脑初态，刺激无/左/右/双侧及多强度多持续时长，记录颈前、颈后、Eon接收群、相关中间群及DN。训练工程尺度/基线/饱和/滤波，使原脑有可区分、不饱和、撤刺激可恢复的响应。能解码左右不等于脑会决策。

2. 路径可达性与第一行为：检查已存在脑内感觉→候选制动/转向DN的结构和实际诱发响应。首任务拟为持续前足机械刺激下减速/停稳，刺激解除后恢复行走；这是拟定工程课程，不预设该AN天然负责停止。若该感觉群只能可靠招募别的行为或不能到达已验地面DN，先查映射/支路，不向DN直注“正确答案”。

3. 行为监督：原有人工正确DN发放→真实颈部→身体轨迹提供可执行的下行参考，不是“原脑已经根据感觉作了正确决定”的证明。另设高层任务教师，用场景状态制定何时停/转/继续的监督标签；身体FlyGym教师只提供执行和局部恢复，不能替代高层决策教师。Eon原生已验证感觉→神经响应可作保持/校准教师，但不能凭原模型当老师就保证新增通路语义。

监督目标先比DN的分群发放率、时序、撤令顺序与实际颈后状态，再比身体行为，不要求不同随机种子毫秒脉冲完全相同。制动参考包括先撤推进、制动再保持200ms的已验时序，但运行时由感觉/脑动态产生，不能按回合固定时间硬编码。误差包含误停/误转、延迟、抖动、残留推进、姿态和旧能力偏离。

4. 真实仿真优化：首轮不做全脑PPO或全长BPTT。少参数Uθ用同种子正负扰动、真实冻结原脑＋真实颈部求损失，估计方向更新；先做小预算可控性/灵敏度试验，若没有有效方向就停止查因。共同随机数降低噪声但不消除离散阈值；保存真实模拟评估与权重，不能用离线拟合误差代替行为。

如需更多参数，另拟合实际神经扰动数据的局部可微代理，仅用于建议Uθ更新；通过小步信赖域与真实模拟复核/拒绝回退验证，最终链路仍是原真实离散模型。不得将numpy路径加requires_grad后称有真梯度。PPO若后续采用，动作是受限感觉编码参数，其策略梯度不需穿过颈部/环境；它仍可能把翻译层变成外部策略，故第一版不采用。

5. 自采偏离：短闭环后收集它自己遇到的失联、延迟、轻触/持续触、左右冲突及误停状态，用高层教师重新标注当下状态，补训再验。这是DAgger思路，不能拿另一只自由运行身体按时间凑标签。分割按完整回合、刺激模式、初态/场景，防止同轨迹切片泄漏。

6. 必要时局部微调：冻结原脑不具备的转换不可能由纯格式转换保证学会。若感觉确已到达正确群，且受约束编码无法诱发所需DN，先查路径；已有路径弱则只调已存在相关突触的有界分组增益/兴奋性，保留身份、符号和原邻接，不添加无来源捷径。独立版本Uθ＋脑局部微调，真实阈值/延迟重放与旧神经反应回归。缺连接不以增益搜索伪造；需要新来源或另立工程假设。永久冻结原脑时，只承诺已证明能诱发的行为子集。

## 首轮验收和控制

先验前足双侧信号到脑可辨，再做实时感觉→脑→DN→颈部→身体的一条简单反应。检查正常、上行全切/单切、下行全切/单切、切后恢复、同历史不同当前感觉、匹配旧命令重放及脑状态钳制/时序打乱。运动下行切断后，不因身体局部站姿/反射继续而判脑仍能控制；比较的是对应脑意图的增量响应。

仅输入零/全静默脑作为控制不足：适配器可能检测零状态切换。应增加正常统计的错配脑状态/打乱因果响应对照，并检查感觉适配器输出白名单。切断在已声明真实轴突/边界操作，不能让切后旧队列脉冲补发；恢复仅新到达有效。无环境输入任务、无接触回合防止靠时钟固定停走。多个未见发放种子/扰动和恢复条件，分别报神经到达、DN选择、身体响应与旧基础能力。

首轮不追求全部九组任务；先用已验证映射和可达路径。MDN右侧缺唯一绑定，后退全双侧不先承诺。冻结完整源/身体/颈部/脑初态和逐更新权重；若代理或微调，记录其身份与实际仿真验证。身体既有原地转向/高度/航向残差与大角度限制继续作为基线，不要求翻译层凭空修复身体。
