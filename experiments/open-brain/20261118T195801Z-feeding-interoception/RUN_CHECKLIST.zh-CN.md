# 摄食与内感觉实施记录

- 运行身份为开源脑 P1 / S5。身体实现位于 `engine/embodied/feeding.py`。实验命令、外部数据版本与哈希校验见同目录 `REPLAY.sh` 及 `sources/SHA256SUMS`。采用归档 Python 3.12 环境和 CPU 单线程 Eon 积分。
- `bench.py BODY` 初次退出 1。恒速中肠排出会在每步送走上一拍进入的营养，留给吸收时间不足。改成按内容量一阶排出后，正式和重放 `BODY_FINAL`、`BODY_REPLAY` 各退出 0，八个产物逐字节一致。另以变化容量和时步检查 5,000 次营养转移守恒。
- `mouth_bench.py` 的正式和重放各 12,000 原生物理步，均退出 0。七个口器、接触、时间和摄入数组逐值一致。
- `probe.py` 运行 127 初版、127 修正元数据字段后的重放，以及 509 留出种子，均退出 0。正式两个种子合计 64,000 脑状态通道步。前版与修正后的 127 神经轨迹 17 数组相同。切断输入和六组到达的 15 步延迟独立逐拍核对。元数据字段修正前的初版 `EON127` 保留，正式证据为 `EON_FINAL127`、`EON_FINAL509`。
- `audit_banc.py`、`figure.py` 和 `bash -n REPLAY.sh` 退出 0，已实际打开四栏证据图。报告没有将筛查施加的 1.5 ms、牵张编码率或候选 Piezo 身份登记为实测。训练更新 0，自主停餐、再进食和生存未验收。
