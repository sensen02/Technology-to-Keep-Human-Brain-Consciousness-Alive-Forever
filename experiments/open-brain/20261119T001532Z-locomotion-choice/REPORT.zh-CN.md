# P1 悬空果与低果的走路、飞行选择

## 原模型

在已有的 FlyGym 觅食闭环中，用可见红果、相同平面气味和口器几何进行配对。低处果子正常步行吃到，2.6 秒累计摄入 0.679 仿真单位。把同样果子升高 3 mm 后，两组 3.6 秒都继续走，最近分别距果心的水平投影 0.055、0.190 mm，口器最近仍离果约 3.04、3.05 mm，双侧 DNp11 均零发放，摄入均零。左侧悬空原版重跑，实际开通并记录起飞颈路，五份原步行数组逐值一致，DNp11 到达仍为零。出原离散气味域的回合使用零外部气味并计数，原越界异常保留在日志。

## 修复

给脑侧翻译层增加由实际眼图学习的果位高度判别。标签来自配对仿真场景，正式回合只用头部眼图特征。先在现有双眼 FlyGym 身体上做定位。在 300 张额外图像上，0.8 置信门下高果召回 84%，低果误发起飞候选 0%。随后在统一 FlyBody 上重新按该身体的成像拟合，227 张留出图像的高果召回 100%，低果误发候选 0%。

翻译层把高果证据送到冻结 Eon 中 8 个经连接矩阵查验的 DNp11 上游神经元。双侧 DNp11 自身由 Eon 递归网络产生脉冲。体端只有收到经过已登记 BANC 轴突、VNC 突触和膜动力学的双侧读出才允许起飞。低果由既有 PFL3 地面意图、BANC 地面下行和预训练 FlyBody 步行策略驱动。统一实验用一副连续积分的 FlyBody 产生状态和感觉。步行策略的观察副本用于构造所需输入，体端没有因切换控制器而重置姿态。20 ms 分块交换信息，神经模型以 0.1 ms 积分，MuJoCo 原生步 0.05 ms。

飞行先使用冻结的飞控。着陆仍用实际眼图触发的工程 DNp10 入口并通过颈部下行，进食使用糖味到冻结 Eon MN9。初次统一高果起飞落果后，第 6、7 腹节碰果，六足站稳的进食门槛正确拒绝。修订后仅在已有果面足支撑时，通过 FlyBody 原有腹肌肌腱执行器抬离果面。身体位置和果面碰撞几何保持连续。

## 近处误起飞回归

第一轮统一身体低果对照在 3.441 秒误起飞。实际眼图的红色区域铺满 256 像素，轮廓裁切把它误判为高果。新增规则只从完整、未贴边的轮廓估高度。被裁切的红色仍留给行走追踪，避免临近后因看不完整而停步。原回合保留于 LOW_CLIPPED_EYE。第二版低果继续步行且摄入 0.0126，但触食后失稳，保留于 LOW_CROP_FIXED_UNSTEADY。最终低果采用由地板承重的果肉斑块，口器触及后在 45 ms 内渐退为站姿。短暂失去口器接触时允许继续走近。高果保留实体承重与腹部离面控制。

## 统一身体的正式对照

果心沿前向距离为 80.3 mm。高果表面高 3.00 mm，底面悬空。低果是果肉斑块，表面高 0.14 mm，地板承重。四个条件使用逐值相同的初始身体状态。两组都由当前感觉驱动，起飞的 DNp11 没有预设发放时刻。

| 条件 | 行为 | 首口 | 摄入（仿真量） |
|---|---|---:|---:|
| 悬空果，启用翻译 | 61.8 ms 启动起飞，83.45 ms 离地，647.45 ms 首足触果，果面六足保持 0.815 s | 0.911 s | 0.24850 |
| 低果，启用翻译 | 步行到果肉边，六足站稳。双侧 DNp11 为 0 | 3.571 s | 0.30450 |
| 悬空果，禁用翻译 | 始终步行，水平上最接近果心投影 0.092 mm，随后走过 | 无 | 0 |
| 悬空果，切断双侧 DNp11 | 起飞阈值前的脑端脉冲与完整组逐拍一致，颈后到达均为 0，继续站立 | 无 | 0 |

高果左、右 DNp11 分别产生 8、5 个脉冲，并全部跨颈，双侧传导为 13 个神经时步（1.3 ms）。切断组在 0.8 秒总计仍发放 92、77 个脉冲。修订前后两轮高果的身体姿态和发放、到达、颈后读出、地面读出、刺激计数、MN9 及进食门七份数组逐值一致。低果与无翻译的时长为 4.44 秒，高果完整为 1.62 秒，切断为 0.8 秒。各自累计量对应各自观察窗。

低果在快速站定的第二次修正仍只摄入 0.02485，原因是停步时口器留在斑块边界，接触反复丢失。最终把停步移到累计触食证据约 0.115 秒后，同时允许小间断，口器留在果肉上并持续摄入。误起飞和中间失败轨迹均保留。

四个正式条件合计 226,000 个原生物理步、113,000 个 Eon 积分步，神经和物理分环境串行运行，每次各自用一副连续物理身体。完整验收见 LIVE_CHOICE_CURRENT.json，复跑入口 REPLAY.sh。对照图和视频由同次轨迹生成。

## 范围

这是训练出来的脑侧感知翻译层加冻结 Eon 的行为选择。当前比较的是同一条直线路径上单个高果或低果。试验未覆盖同时摆放两枚果子、复杂地形先走后飞、成本最优路径、空中搜寻或原生 Eon 的高度决策。无 Eon 权重更新。项目 P1 的旧飞行、地面和 P2 档案均保留。
