# P1 果园承重换步与同果实摄入复验

健康 P1。原始两处地面入口采用上轮 S3 头侧策略、冻结 Eon、17 条具名下行经 BANC 和原物理身体。近果测试采用同一颗 Blender 苹果 ground-003 的原生上侧果皮。两类试验分别报告。

## 原地面起点的配对实验

表中每格依次为稳定行走门（1 通过）、起步窗口净位移（mm）、首次接近的 1 mm 档数、跌倒时刻或完成时限（秒）、末段站稳（1 通过）。初始站姿、6.4 秒时限、0.16–1.2 秒起步窗口、末段 140 ms 条件与前轮一致。

| 神经种子 | 入口 | 同一头侧、原身体 | 同一头侧、修复身体 |
|---|---|---|---|
| 37 | CLEAR | 0 / 2.35 / 1 / 0.471 / 0 | 1 / 3.36 / 1 / 跑满 6.4 / 0 |
| 37 | DEBRIS | 0 / 0.44 / 0 / 跑满 6.4 / 0 | 0 / 2.01 / 2 / 跑满 6.4 / 0 |
| 53 | CLEAR | 0 / 2.32 / 1 / 0.535 / 0 | 0 / 1.21 / 2 / 跑满 6.4 / 0 |
| 53 | DEBRIS | 0 / 1.07 / 1 / 4.702 / 0 | 1 / 2.79 / 2 / 跑满 6.4 / 0 |

同种子 37 的更早原头侧对照，开阔及草枝分别于 0.56 秒与 4.46 秒跌倒。所有种子与入口的相同行比较均验证同一初态、头侧首次决策前的身体轨迹及 17 路下行发放。每条通路按其延迟核验到达。采用足端接触及躯干姿态判稳。净位移含侧移。是否接近食物另看距离档。

八个开发回合包含 2163 个 5 ms 样本，其中 64 个在跌倒前 80 ms，另外提取 1720 帧承重移动姿态。开阔的一段轨迹在倒前仅剩左侧三足接触，草枝另一段仅剩右前和右后足。用当前六足接触、躯干方向及竖直速度拟合正则化逻辑回归，按风险将各腿目标混合到实测承重姿态，调节承重足附着。预警分数在训练正负样本上的均值为 0.760、0.240。控制器只接收当前身体状态及既有颈后步态。

## 同颗苹果上的进食正例

原两处下侧食斑扫描每处 14,000 个收拢口器姿态。启用原生口器关节后每处再扫描 21,000 个姿态。按预设站姿、0.55 mm 水平距离和 0.02 mm 果皮穿入容差，采样中均未发现合格初态。原飞行身体保留口器几何、关节，但会移除口器执行器。派生近果试验启用 FlyBody 自带口器执行器，从同颗果实原三角面取上侧局部，在重力下落足。足端实际接触带食物标签的皮面时，局部反射驱动原口器和腿部执行器。该标签是跗节味觉的工程代理。近果反射和原入口行走策略分别验证，原路线尚含接近和登上果实的过程。

| 诊断组 | 源果皮面 | 首次摄入（秒） | 真实摄入 | 库存减少 | 末段站稳 |
|---|---:|---:|---:|---:|---|
| FOOD_off | 483 | — | 0.00000 | 0.00000 | 否 |
| FOOD_on | 483 | 0.1138 | 0.90000 | 0.90000 | 否 |
| FOOD_release_off | 279 | — | 0.00000 | 0.00000 | 否 |
| FOOD_release_on | 279 | 0.1138 | 0.18130 | 0.18130 | 是 |

每笔正摄入均对应口器物理门、Eon 的 MN9 摄食读出和库存减少。每个近果开关对照从同一物理姿态起步。第一组开启反射时吃完整份 0.9，末段有五足接触，但胸部竖直方向余弦约 0.929，低于原 0.94 门槛。第二组以身体实际摄入达到 0.18 为条件释放进食姿态。各组完整原始数据、初态和参数均保留。

## 同一身体的整合复验

可运行入口 run_recovery.py 在同一套 FlyBody 上保留已训练的承重纠正、口器执行器和接触进食。遇到果皮时根据当时姿态计算屈腿目标。整合平台使用同一个 S3 头侧检查点。下表均为种子 37。寻路从原地面起步。局部诊断从同源果皮起步。

| 起点 | 稳定起步 | 接近档数 | 跌倒时刻 | 摄入 | 末段站稳 |
|---|---|---:|---|---:|---|
| ALL_CLEAR | 通过 | 3 | 4.110 秒 | 0.00000 | 否 |
| ALL_DEBRIS | 未过 | 2 | 1.695 秒 | 0.00000 | 否 |
| ALL_FOOD | 未过 | 0 | 无跌倒记录 | 0.18130 | 是 |
| PASSIVE_CLEAR | 通过 | 1 | 无跌倒记录 | 0.00000 | 否 |
| PASSIVE_DEBRIS | 未过 | 2 | 无跌倒记录 | 0.00000 | 否 |
| PASSIVE_FOOD | 未过 | 0 | 无跌倒记录 | 0.18130 | 是 |

近果正例的首次摄入早于 0.16 秒的首个头侧决策。本轮将其用于验证身体取食、脑摄食读出及库存转移，第三轮头侧寻路训练仍需从果皮之外收集可影响最终摄入的接近轨迹。

## 口器待机复验

ALL 保留已启用原生口器执行器的默认待机状态。PASSIVE 仅在足端实际接触果皮时恢复新增口器执行器的原生增益和偏置，离开后归零。原有头、腿、被动关节和碰撞继续按模型运行。触发记录和两组增益保存在各回合 ORAL_ACTUATORS.json。
在 CLEAR 原起点，口器由关闭转为开启 0 次。与仅修承重的同种子回合比较，全部身体姿态逐值相同为 True，颈后到达逐值相同为 True。
在 DEBRIS 原起点，口器由关闭转为开启 0 次。与仅修承重的同种子回合比较，全部身体姿态逐值相同为 True，颈后到达逐值相同为 True。
