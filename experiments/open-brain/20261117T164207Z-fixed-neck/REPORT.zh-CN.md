# 固定颈部动力学升级与地面复验

完成固定电导版颈部和接收靶点模型，52 根 BANC v888 轴突保留原解剖身份和突触连接。57 个完整地面条件全部通过既有工程门，57 个新进程独立复跑的神经发放、过颈到达、身体动作和保存的物理数组全部逐值一致。正式及复跑共 2,034,000 原生物理步。可塑性关闭，Eon 原脑和身体网络权重均冻结。当前结果适用于本分支标称固定参数，文献先验和待校准项如下。

| 环节 | 本轮实现 | 参数依据 |
| --- | --- | --- |
| 各轴突传导 | 按两颈切面间真实 SWC 连续分支逐段求弧长，52 根各自有路径和队列 | 实测弧长 120.39–148.06 µm；速度 .10 m/s 为工程先验，名义连续时延 1.204–1.481 ms，.1 ms 步进向上取整后 1.3–1.5 ms |
| 突触释放 | 单独延迟 .3 ms 后产生双指数电导 | 跨细胞实验参考下的固定假设，与跨颈时延分别记账 |
| 兴奋突触 | nAChR 电导上升 .2 ms、下降 1.1 ms，反转电位 0 mV | 果蝇其他细胞测量和固定电导研究模型的先验 |
| 抑制突触 | GABA 上升 .5 ms、下降 5.4 ms；GluCl 上升 .5 ms、下降 5 ms，两者反转 −60 mV | 抑制下降及反转电位来自研究模型引用参数，上升时间为工程假设 |
| 膜响应 | 漏电导、电容、各类电导共同决定瞬时平衡电位和时间常数，每步解析更新；保留阈值、reset 和不应期 | C=20 pF、gL=1 nS 是明确的归一化选择，维持原 20 ms 静息时间常数。EL/reset −52 mV、阈值 −45 mV、不应期设定2.2 ms；离散触发最小2.3 ms |
| 受体和突触强度 | 根据真实来源细胞的递质确定正电导类型，原正数突触数进入连接；静息小信号电压面积与旧模型兼容 | 神经递质含验证与预测注释；量子电导面积是工程匹配值 |
| 身体适配 | 按 13 组独立神经刺激、8 档固定频率拟合单调静态读出，共 26 个具名左右映射 | 神经标定没有身体运动目标参与，运行期间固定。原动态瞬变和新时延仍实际经过神经模型 |

沿用文献的部分参数来自其他通路。52 根普通通道的真实轴突速度、每个靶细胞电容和受体密度仍缺直接测量。巨纤维的实测速率只作为背景参考，未用于替普通轴突赋值。现有重建段两端之外，脉冲起始点至前切面、后切面至末梢的距离和延迟仍标未知。本轮仅建立契约内的受体、端口和首跳神经元，完整递归 VNC 局部网络仍待实现。 [突触电导参考](https://pmc.ncbi.nlm.nih.gov/articles/PMC13126034/) · [胆碱能上升动力学参考](https://projects.iq.harvard.edu/files/wilson-lab/files/gouwenswilson2009.pdf) · [巨纤维特定速度测量](https://pmc.ncbi.nlm.nih.gov/articles/PMC6709211/) · [原模型参数](https://pmc.ncbi.nlm.nih.gov/articles/PMC11821855/)

电流依赖瞬时膜电位，在反转电位附近减小。测试把同一抑制电导分别施加到 −52 与 −70 mV，所得电流分别为负和正，符合 −60 mV 的反转关系。放电 reset 和不应期期间继续保留未衰减的突触电导。解析积分核面积、静息恢复和时间步减半比较均有记录。单脉冲参考最大电位误差为兴奋 .286 mV、抑制 .050 mV，参考包含传导步长量化。每条发放的具名传导和切断恢复独立复算。短脉冲测试中47根通道发放，其余5条上行在持续受体输入下均能发放，并通过逐根时延和切断恢复核验；原版在同一持续输入下也会发放。两种刺激条件都保留。

原读出直接使用新膜电位的10条开发条件中，9条通过，DNg60的制动末窗速度RMS为1.064 mm/s，超过.30门。固定神经标定后同10条开发全部通过。正式选择在完整留出前固定，随后进行全部57条回归。

敏感性采用速度 .05/.20 m/s、突触上升下降同时乘 .8/1.2、漏电导乘 .8/1.2，分别测试五种开发动作，总共30条。29条通过。漏电导增加20%时，DNg60仍显著减速，制动窗漂移 .0146 mm，但速度RMS .896 mm/s超过.30门。该失败表明DNg60对膜漏电导和接收侧标定有依赖。标称固定模型的通过与该参数范围的失败分别记录。原地转向和完整D1–D8不在这次既有通过动作的回归范围。飞行按用户要求暂缓。

本轮是手动研究实现。当前开源脑项目入口见 NECK_DYNAMICS_CURRENT.json，原始归档继续可复验。可用新目录的 drive.sh regress.py 和 run_formal.sh 调用同一固定实现。现有受控模型参数为离线选定，运行期间没有学习或适应状态。六栏同次物理视频100帧全解码，已实际查看动力学曲线、响应曲线和关键姿态。
