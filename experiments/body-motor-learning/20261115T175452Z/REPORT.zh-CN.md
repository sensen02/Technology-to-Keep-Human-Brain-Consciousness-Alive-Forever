# 六腿身体侧运动网络首轮训练与真实物理结果

范围为人工搭建大脑项目的身体侧台架。新网络包含共享逐腿编码、逐腿循环记忆、全身循环协调和 42 维有界关节动作。身体读出与执行沿用已验收平地派生体的实际具名布局，5 ms 神经决策、1 ms 目标积分、12.5 µs MuJoCo 原生积分。器官模型、人工脑和颈部没有参与本轮台架。已验收旧权重用于证据身份核对和独立教师接管诊断。

## 实际训练

合格直走和初态扰动 seed11、独立核验过的停步台架及左右低平移转向作为物理示范。seed12 直走整条留出。停止教师正式停步验收缺失，训练使用的是它在已验证安全范围内的减速与支撑记录。全部 480 次监督模仿更新完成，约 39.4 s，逐更新权重及优化器随日志保存。最终只用 step 480。留出直走动作误差 MSE 为 0.00044368，训练前约 0.07359879。旧通过对象不被替换。

## 同一权重独立身体验证

| 条件 | 实际结果 |
|---|---|
| 直走 | 撤辅 0.807 s 早停。最低 COM 0.676，推进为负，六腿周期未完成。 |
| 从预热状态停步 | 撤辅 0.865 s 早停。最低 COM 0.680，含非足接触，漂移与低速门失败。 |
| 左转 | 撤辅 1.055 s 早停，偏航 −19.42°，方向相反。 |
| 右转 | 撤辅 0.782 s 早停，偏航 −11.87°，未达到 45°门。 |
| 无步行预热的连续过渡 | 首个 3.2 s 站立窗口未早停但低漂移与速度门失败。第一次起步后 0.214 s 早停，未进入再停和再启动。 |

五个条件均完成新进程保存动作重放，最大误差低于 1e-10。技术重放通过与行为失败同时保留。所有独立条件的实验身份、结果、动作、1 ms 物理轨迹和重放记录在 EVAL 目录。步行和停步候选的预热实测观测与教师动作分别逐位一致，接管首帧的身体观测也逐位一致。

## 失效诊断与下轮数据

- 平地直走在接管第一帧的动作 RMS 差 0.01360，25 ms 后 0.20711，50 ms 后 0.28801。这些后续帧已处于不同物理状态。25 ms 时 5 个观测维度达到标准化裁剪阈值。
- 冻结由新模型实际观测形成的循环状态，仅在 25 ms 的一次离线推断中用归档上一动作替换实际上一动作，输出距归档动作 RMS 由 0.20711 降为 0.09568。50 ms 对应 0.28801 降为 0.16470。首帧输出对上一动作的局部 Jacobian 最大奇异值约 2.50。此诊断不等同于把归档动作贴到新状态作为标签，也不确认唯一原因。随后预登记同预算屏蔽上一动作的单因素对照。
- 独立实际物理诊断先让新模型控制 25 ms，与失败回合的实际 X238 和动作前缀逐位相同，然后由旧通过网络以真实状态连续接管。完成 2.4 s 短窗，最低 COM 1.25849，前进 .07153 原生速度，非足 1 ms 峰值零。短窗滑移比 .57687 高于 .5，保留失败。该回合支持将旧网络用于有限早期偏离状态的教师查询。后续应先扩充多初态与多时刻的可恢复样本，再训练闭环修正。

本轮无 PPO 与完整三部分闭环验收。S2/S5 原生接触、D1–D8 与正式视频未执行。使用第一个实验目录的冻结输入及已有 Python 环境。训练、五组物理与新进程重放、接管诊断各自退出 0。
