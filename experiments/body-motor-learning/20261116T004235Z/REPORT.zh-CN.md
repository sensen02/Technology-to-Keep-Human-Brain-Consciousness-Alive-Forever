# 平地原地转向与行走弧线转向

本轮沿用已验收平地身体与有限关节执行器。现有站稳和直走控制器作为同一身体侧入口的底座。通过前进、偏航两个离散意图组合得到静立、直走、左右原地转与左右弧行。研究范围为原三球脚、原摩擦和重力、无附着的身体台架。模拟从完整快照出发，运动分段之间没有物理重置、根运动写入或外力。

## 示范怎样形成

- 原地教师第一轮可持续转约 75°，质心漂移约 0.32 体长。该轮位移在 XY 面的几何形状符合绕偏心点运动。教师只在私有逆解中把预期旋转中心向前校正 0.76 原生单位，让物理脚步负责转身。新教师的左右实际峰值漂移分别降至 0.01460、0.01378 体长，转角分别为 +74.93°、−75.11°，两组尾部站稳。
- 弧线教师在已通过的直走之后，让身体绕私有参考圆弧前进。支撑足有地面锚点，摆动足规划前方落点，关节只通过原有有限执行器改变。右弧原配置通过，得到 −57.21°、沿躯干方向 0.12033 原生单位/s 与 0.33448 弧线滑移比。左弧的初始三个配置保姿态和推进，但都有非足触地。重建原轨迹确定擦地体段为右后第四跗节，首条累计 751 个毫秒样本，峰值 0.21139 原生力。
- 左弧后续补足部姿态时，以既有足端位置雅可比的近似零空间增加第四跗节净空。该方法只改变教师关节目标，接触几何、足载门和真实根自由度沿用原配置。失败记录逐一保留。
- 0.012 与 0.028 原生长度净空两个教师都通过。0.028 配置提供更大的几何余量，转角 +56.66°，毫秒滑移比 0.43131，满足 0.5 上界，因此选它入库。0.012 配置的毫秒滑移比 0.32689 也保留。

## 身体策略怎样学习

四条合格的转向教师各提供 1,920 个本体观测与动作配对，共 7,680 个。执行时用当前关节角和执行器目标选原型，按目标差提供反馈修正，再由原执行器限速。身体侧没有循环状态或归档时钟。转向意图撤销后，前进为 1 时回到直走，前进为 0 时回到已有的站稳分支。偏航命令为离散的左、无、右，本次预设命令窗口，尚无给定任意目标角后自行截停。

## 原生步转向和站稳

| 项目 | 左转 | 右转 |
| --- | ---: | ---: |
| 原地转向窗净转角 | +74.93° | −75.11° |
| 原地转向窗质心峰值位移（体长） | 0.01460 | 0.01378 |
| 弧线转向窗净转角 | +56.66° | −57.21° |
| 弧行时沿身体朝向速度（原生长度/s） | 0.11874 | 0.12033 |
| 弧行时逐足最大滑移比（门槛 0.5） | 0.43054 | 0.33501 |

四个标称回合共 5,152,000 个原生物理步，1,280 次与冻结接触记录器的力核对通过。整个四回合都无非足触地和额外力，转向窗内六足都完成真实卸载、摆动及落地再承重，转向窗最低 COM 分别为 1.25148、1.25880、1.25180 与 1.25775。原地转最后 200 ms 净偏航仅 0.00269° 与 0.00485°，达成末窗站稳。直走进入弧线前的 4.8 s 原生滑移比 0.47560。

四个留出回合分别从右倾、前向速度、左倾及后向速度快照开始，各跑一次，并通过同样的毫秒工程检查。扰动只用于较早的快照准备，本轮转向过程中未施加主动推力。统一策略入口在新进程以倒序输入复验八条实际回合，动作最大误差为零，旧标称直走及站稳 2,260 次动作逐位相同。四条原型教师、示范样本、控制器输出、物理轨迹与同次媒体均保存散列。

## 出弯接续

直接切换到原直走策略时，两侧都沿出弯朝向继续推进 4.8 s，速度分别为 0.06500 与 0.07730 原生长度/s，残余偏航 −0.23° 与 −1.82°，再撤销前进即站稳。使用原直走公式新增诊断时，出弯窗的滑移比分别为 2.112 与 1.560，均高于 0.5。切换后的第一个决策就有 30／26 路关节速率达到上限，前约半秒明显拖脚，后半窗个别足也有切向滑速峰值。原先登记的转向和接续推进验收通过，低滑移出弯质量门失败。

从两条实际转向策略的末态分别连续补采锚足直走教师，物理状态、质心、航向和执行器目标与原试验在接手时逐位相同。左侧教师继续走 0.07687 原生长度/s，末窗站稳，滑移比 0.792，主要峰值出现在第二次换脚附近。右侧继续走 0.07966，滑移比 0.342 通过，但接回原站稳控制后末窗速度 RMS 为 0.0260 体长/s，高于 0.01，两种修正回合均未进入正式原型。下一步分别收集左侧前两次换足的纠正动作，以及右侧出弯末态减速和落足后停稳的成功动作，再整条留出评估。

## 可复验交付

- `turning.py` 和 `control_body.py` 提供身体台架与六个离散动作的统一入口，`BUILD.json` 保存四条教师与原型对应关系。
- `FINAL_ACCEPTANCE.json` 对应预登记转向与出弯推进判据，保存完整接触、站稳及低滑移附加诊断所用证据链。两个对照视频取自同四条原生步回合，分别完整解码 566 与 1,046 帧。原地及弧行的关键帧均实际打开检查。
- 本轮结果适用于平地、三个球形接触垫、有限 PD、固定 9.6 s 转向以及规定的弧线进入时机。验收范围为身体侧研究原型，缺任意步态相位、在线受力、复杂地形、足垫附着、生物步态和真实颈部连接的证据。
