# 踏空后再起步与备用足接地

本轮继续人工搭建大脑项目身体侧 S2/S5。两位子代理在同一冻结 71 mesh 身体、42 路有限 PD、12.5 μs 积分步、无附着和无额外施力下，分别验证实际踏空停稳后的再次起步，以及另一条未承重腿的主动接地。脑侧和真实颈部功能仍使用独立验收口径。

## 改进一　停稳后的再起步

从之前同一个全态站姿开始，重跑实际右前足踏空、局部制动、换落点和静止恢复。到试验时钟 6.450 秒为止，新试验的标准毫秒轨迹、动作及 516,000 个原生步的接触和姿态均与上轮停稳记录逐字节相同。这个时刻重新在身体台架发出推进指令，撤去局部制动，交给原有冻结前进策略。中间不重置积分态或修改根位置，也无额外的姿势对齐动作。

第一个完整换步来自右中腿，在重新推进约 744 ms 后完成。其抬足、前移和重新承重均达原有周期判据。随后完整走动 9.6 秒并在撤令后 1.2 秒站稳，六腿周期 LF/LH/LM/RF/RH/RM 为 1/2/2/2/2/2。有符号前速约 0.071633 原生长度/s，原生最大滑移比 0.481433，小于 0.50，地面非足接触力峰和额外施力为零。

前半段完全相同但继续制动的对照保持静立，配对走动窗的前向净位移约 1.25e-9 原生长度。独立再起步的回合完整 17.25 秒，共 1,380,000 个原生步。两条复验都通过同一门。验证的是收到再次推进指令后的连续物理动作，上一轮踏空制动仍是状态化教师。 [原生指标](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/restart/RESTART_AS/NATIVE_AUDIT.json)

再起步的独立回合与正式回合的轨迹、决策和原生记录逐字节复现。续走的 9.6 秒内，右前足在原缺口底与边缘的原生承重计数均为零。 [配对资格](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/restart/RESTART_ACCEPTANCE.json) · [再起步检查表](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/restart/RUN_CHECKLIST.zh-CN.md)

## 改进二　原先悬空的备用足接地

本组独立选取右后足预计着地、左前足仍悬空的运动相位。地面是固定几何的真实缺口。早期 A 的接缝影响左后足，另存失败。C 布局中实际缺口和填平试验到 4.258 秒姿态逐字节相同，才在右后足接触前后分开。填平臂的晚期地面接缝仍影响完整行走，该臂用于检测窗口局部配对。

两组的右后足收腿与其他支撑脚的保持逻辑一致。4.280 秒右后足在缺口内为 0 W，足垫底面低于上沿约 0.0105 原生长度。填平场景同刻开始有约 0.00314 W 的右后足支撑。新增左前足动作之前，两臂的原生姿态、触力、足端位置逐字节一致。此前连续 20 ms 左前足载荷为 0，最低净空仍约 0.00888 原生长度。

D 组首个不同动作只作用左前腿七路有限 PD。真实上沿载荷从 4.3070 秒开始连续 39.1 ms 不低于 0.02 W。前 20 ms 的最低值是 0.020193 W，同一 20 ms 关闭左前足动作的对照为 0 W。该对照首次连续承重于 5.1212 秒，比主动组晚 814.2 ms。D 的独立复验轨迹、决策与原生接触数组逐字节相同。主动组后来失稳并在 5.468 秒终止，关闭组最终站稳。这个回合验证实际提前接力，终末稳定门另行判断。 [D 试验消融与原生复验](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/support/DIAG_D_FOOT_ONLY.json) · [缺口几何配对](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/support/SCENE_PREFIX_C.json)

较轻的 C 与 0.055 原生长度目标降幅可完成 8 秒试验并站稳，左前足承重未达到 0.02 W 连续 20 ms。较大的固定幅度、接触后淡出、退回到较轻目标以及使用实测力的闭环补撑都进行了物理比较。最后的小幅定点及限幅触力调节仍未同时做到较早持续承重与终末站稳。本文只接受凹槽后的主动接地与确切承重时段，不将其登记为完整稳定的补撑策略。 [补撑运行账目](/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T071419Z/support/REPORT.zh-CN.md)

两项试验在各自真实缺口和连续积分中完成。再起步的身体台架通过，备用足主动接地的因果证据通过，备用足联合停稳待修。上半段恢复教师和补撑教师均带工程状态；此次任务未训练新网络。后续可以在维持其余脚接触和姿态稳定的条件下，重新检查左前足接地后的受力转移与安全撤出。
