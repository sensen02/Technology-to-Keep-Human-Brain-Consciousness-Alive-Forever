# 踏空后在同一回合重新起步

AS 缺口上的首项改进通过。身体从完全相同的冻结站姿开走，右前足在 2.764 秒实际失载，旧局部教师在 2.765 秒制动收腿。右前足移出缺口，在 3.127 秒重新取得连续上表面承重，然后站稳。台架在 6.450 秒再交付推进意图，直接恢复原冻结的行走策略。整个 17.250 秒连续积分，间中没有重新加载姿势、改根坐标、改地形或施加外力。

| 续行测量 | 实测 |
| --- | --- |
| 第一个完整换步 | 右中足在续令后 744 ms 完成 |
| 9.6 秒续行 | 六足按 LF、LH、LM、RF、RH、RM 分别完成 1、2、2、2、2、2 次完整周次 |
| 续行窗前进 | 0.687677 原生长度，0.071633 原生长度每秒 |
| 续行原生最大滑移比 | 0.481433，低于 0.50 |
| 右前足洞底／边缘再接触 | 续行窗的有载原生步均为 0 |
| 撤令后止步 | 1.2 秒窗内通过末段站稳验收 |
| 无续令对照 | 从同一站姿保持不动，配对前移 1.25e−9 原生长度 |

两组与上一轮已验收停稳试验到 6.450 秒的轨迹、决策、原生记录全部逐位相同。续行组独立重积分 1,380,000 原生步，整体三份物理及动作 NPZ 的 SHA-256 分别与首次相匹配。对照也记录同长 1,380,000 原生步。两组重新送意图之后的命令均直接来自原推进／静立策略，没有叠加额外的再起步动作。三份物理求解记录合计 4,140,000 原生步。

验证范围是一个缺口和一个实际恢复姿态。首段使用旧局部制动教师，续行请求由台架给定。该结果验证安全暂停让旧运动策略继续工作。主动具名脚增载、脑侧选择续行时机、真实颈部通讯及完整 D1–D8 各有独立验收。
