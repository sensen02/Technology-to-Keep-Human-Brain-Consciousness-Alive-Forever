# 连续调速与行走转向衔接（S2/S5）

用户已裁定上一阶段按实测范围收口。本轮委派连续调速、双向弧行和出弯、监督候选及独立组合验证三个任务。运行目录 `/run/media/sensen/Data2/cell_wound_prototype/experiments/body-motor-learning/20261116T075254Z`。归属人工搭建大脑项目的身体台架，沿用完整 71 mesh、原三球足端、无附着、42 路有限 PD、12.5 μs 原生步、5 ms 决策和冻结全态快照。原成果与旧出弯失败分别保存。

- 跨越同一连续回合核对关节动作、具名接触、停稳、质心和实际推进。加减速用低、中、高命令窗和实际速度时间序列判断，报告有符号前速、在行走窗的滑移、支撑、非足接触及速度随命令变化。零推进静立另使用旧站稳门。
- 双向转弯核对净偏航、沿体轴推进、真实换足与否，出弯撤销偏航后保持推进，报告沿所得朝向的继续走动、残余偏航、逐腿绝对滑速、原生滑移比和末窗停稳。原直接切换 0.5 出弯上限与正向推进条件保留。任何短窗或新指标须明确口径与源指标差异。
- 教师可用独立声明的接触锚点、相位和参考，但只接受实际同身物理轨迹后才训练。学习入口只读当前局部观测、当前推进和偏航意图，不含过去动作、教师时钟或循环隐藏状态。控制来源与练习阶段记录在同一时钟。
- 主张组合能力需同一冻结策略、初态和整段同时满足适用指标。旧身体能力作回归，候选与基线各有独立物理、权重、动作、失败和录像。完整 D1–D8 及脑颈路由另行验收。
