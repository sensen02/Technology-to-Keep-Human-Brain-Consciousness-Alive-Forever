# 联合脑与具名颈部控制复验

- 人工搭建大脑项目 P1/P2、S2/S4/S5。同一标称站姿、完整 71 网格与 18 足垫、42 路有限执行器、无附着和外力。物理积分 12.5 μs，身体与联合脑动作门 5 ms，真实双眼发布 20 ms。场景参数来自 SCENES.json，两个版本的门槛和身体相同。
- 四根下行 DNa02/DNg97、四根上行 AN06B002/AN19B004，均保留原左右根身份、解剖/连接证据和投射。绑定通过一个同源队列，延迟参数 2 ms 为工程假设。视觉由头部直接到人工脑。离线样本含关节与运动真值用于预测监督，在线脑输入没有这些真值。
- 归档 Python 3.12、MuJoCo 3.9、Torch 2.5.1 CPU 同此前；EGL 及单线程 BLAS/OMP/MKL。setup 脚本生成 UNIFIED_BINDING.json 和 BRAIN.pt。检查点包中原共享脑、动作门和预测头逐张量保持。加入同 checkpoint 的冻结视觉分支和显式视觉运动提议，躯体按颈后速度、偏航执行，互斥档位。当前版不含 SAC 更新。
- 第一版执行 unified.py 与 suite.py 成功。左、右转向和末态站稳本身通过，转后接回前进与距离门都未过，留存旧回合。物理诊断发现侧触为零，但旧走停 GRU 把视觉等待与触碰暂停等同。新目录只更改脑输入的意图时序。视觉主动停时撤掉运动提示，重新提出运动时原 GRU 可重启。真实侧碰时视觉仍要求推进，原触觉停步可保持。没有重置隐藏状态。
- 修正前留档输入复算在左右两例分别于 3740 ms、3260 ms 得到首次不同的脑指令。三个上行对照在这次仅重放旧输入的测试中命令逐值一致。真实复验独立执行相同八例。
- reward_audit.py 读取并核验归档物理轨迹哈希，评分 13 个实测重放条件、11 个构造轨迹及抵达/碰撞同时发生等逐步边界。终止分、距离塑形、计时和允许浅坑踩底代价分列。返回的截断标记保留目标值自举。旧坑数据无身体接触部位，体部触坑只做评分规则构造试验。
