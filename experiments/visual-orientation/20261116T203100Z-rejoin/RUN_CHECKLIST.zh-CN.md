# 远障碍重追修复（P1/P2、S2/S5）
固定父实验真实盒、红标、原站姿、71 mesh、18 个足垫、42 有限 PD、12.5 μs、5 ms 控制和 20 ms 眼图。真实来源 DNa02 与 DNg97 经原 2 ms 工程队列。短组利用 B 或 A 的同一归档 qpos、qvel、ctrl 建立对照，其他运行内部状态重新初始化，完整回合使用原站姿且连续积分。真实眼图在环，不重喂旧眼图。NATIVE 与盒力保留逐步记录。
- B 短检测仅换视觉处理，原组必须维持不动，新组实际颈后推进≥1 s 且有符号前移≥.12。两组均无触盒、无地面非足、COM≥1.20。
- A 短对照检验持续右转与撤令后再给定右转脚本，分别以最后 3.6 秒偏航绝对值 <.3° 和实测右转≥3°作工程诊断。脚本经原下行，不作脑策略行为验收。
- 整场使用 B 的路径长度增加视觉重追，连续转向请求上限 3.2 s 后留 0.9 s 释转，以后仍依实际眼图。沿用非碰撞、首次转向净空、全身过箱 .03、恢复视觉推进、目标范围 1.18–1.72 与站稳门。
- 命令使用本目录 `drive.sh`，绑定父项目归档 Python、EGL、OMP/BLAS/MKL 单线程。无新 PPO 或权重训练。
- B 短窗重新迈步后与箱擦碰。完整另测 `./drive.sh wider.py wider`，将初次斜走从 1,100 个眼图周期延至 1,570 个，其余验收不动，配置与下游实现由 `WIDER_INPUT.sha256` 登记。依据旧斜走实测，9.4 秒预计能额外向侧面移动约 .68 原生长度，再回转以留足空间。
- A 的首轮短窗口复建使用站姿执行器参考，两个组都重新右转。另做 `./drive.sh pivot_probe.py PIVOT_TARGETS`，恢复归档执行器目标和足高变化，先让右转沿来源队列到达再积分，比较持续右转与 500–1,400 ms 撤令。先验工程门继续使用持续转不动、撤令后至少右转 3°、无触盒和非足接触及 COM≥1.20。

## 实际退出与复验

- `./drive.sh rejoin.py <模式> <模式>` 中 old/new/turn_hold/turn_reset/full 分别退出 0/1/1/0/1。new 右中足擦碰，turn_hold 的首轮重建未复现持续卡滞。完整原宽组虽恢复推进，仍碰盒。恢复执行器目标后的 `pivot_probe.py PIVOT_TARGETS` 退出 0，并通过全部机制诊断门。
- `./drive.sh wider.py wider` 退出 1，盒力逐样本为零、全身越过、重新前进和减速门通过，预算止点距离和站稳未过。`WIDER_INPUT.sha256` 复核通过。`audit_pair.py` 的短 B、短 A、原 B/加宽三项及 `audit_physics.py` 加宽质量审计均退出 0。
- `./drive.sh finish_visual.py finish` 退出 1。独立从加宽终态复建，真实距离达到 1.297，视觉估距仍高，未触发停车且末端仍转向。该诊断独立归档，不能与连续回合作一次通过。
- `render_far.py` 使用同次归档回放，加宽、短窗和独立停车诊断视频分别为 1,126、76 和 208 帧，全解码及实际打开关键帧。未训练新权重，未执行 PPO，近距视觉校准下轮单独复验。
