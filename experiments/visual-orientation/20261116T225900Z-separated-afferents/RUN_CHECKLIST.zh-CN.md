# 承重与侧碰分离（P1/P2、S4/S5）

- BANC v888 来源拆分。先用官方 v2 边和颈前标记筛选 T1 前足钟状感器的直接受体，验证左右 AN19B004 发布完整 SWC、GCS generation/MD5 和连续跨颈几何，使用真实脑靶投影。侧碰沿用 AN06B002，推进沿用 DNg100。2 ms、增益 1 和地面法向力的线性输入为工程假设。
- 验收采用冻结 71 网格身体、名义起点、12.5 μs 原生步。仅在分离试验的目标前足调整与平面相碰的许可，以构造可控卸载。侧向探针仍能物理接触两种支撑条件。实际测量地面脚垂直载荷，侧碰以探针物理接触为真值，另查非前足探针接触、非足地面力和质心安全。无外加推力。此受控干预用于感觉分离，独立走动数据用于自然任务预测。
- 16 组 64 回合，按整组划分 8/4/4，测试侧碰峰值阈 .01、承重中位力下限 .05 W、无载上限 .02 W，脑读出界 .035 W。留出所有四组合、两侧均正确，侧碰时延门 15 ms。源静默另一类型时须保持未操作输出。
- 上轮 80 条物理走停与侧碰只读重放，通过新来源队列发送先前保存的信号。负载保持最近一次 5 ms 样本，触觉来自实际 1 ms 原生接触汇总。重放不增加物理积分。
- 通路门通过后拟合脑侧因果 GRU，双头预测未来 20/50/100/200 ms 侧碰和前足正常负载。使用全量、触觉与命令消融、感受缺测对照，按整组对比持值及前轮触觉。保存权重、输入证据和独立重放。预测训练不给身体发动作。

## 实际执行

- 归档 Python、MuJoCo、EGL、BLAS/OMP/MKL 单线程。`candidates.py`、官方骨架下载及 `bind.py` 退出 0，骨架及固定针文件 SHA 留档。原通路数据保留。
- 先 `./drive.sh separation.py SMOKE 0` 完成四组小跑，再以八个工作进程 `./drive.sh separation.py DATA <组号>` 执行 64 回合，全部退出 0。后用 `check_separation.py DATA SEPARATION_ACCEPTANCE.json` 独立分离及断线/静默验收退出 0。归档配对复核退出 0。工程幅度阈值使用预声明值。
- 四个 `./drive.sh replay.py WALK_REPLAY <组号>` 退出 0，实际 80 个既有物理回合经新图重播。每条保存原物理指纹。没有新增原生积分。
- 分离通过后 `./drive.sh fit_forecast.py DATA WALK_REPLAY MODEL <full|without_load|without_command>`，各 420 次退出 0，随后以 `audit` 在新进程加载并运行留出评估，退出 0；源码哈希复验通过。实际消融是承重和指令副本，感受缺测在独立断线对照中验证。走动前足负载达实测预测指标，触前侧碰未达使用门。
- `evidence_plot.py DATA SEPARATION.png` 退出 0，实际检查四象限曲线，再复制到桌面并验字节。
