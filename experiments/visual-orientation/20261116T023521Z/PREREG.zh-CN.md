# 平地视觉定向首课（P1/P2）

冻结已验收的平地三球足、42 路有限 PD、5 ms 身体决策和 12.5 μs 原生步。仅在加载完整初始快照时恢复根。正式视觉输出通过经来源核验的左右 DNa02 工程传输。无辅助根运动、运动教师背后接管或额外施力。

第一批身体标定用标称快照，500 ms 站稳，左右各 0.8、1.6、2.4、3.2、4.0 s 偏航脉冲及空指令，撤令后连续积分 1.2 s。报告净转、首达 1° 时刻、撤令余转、200 ms 末窗站稳和全程非足接触。至少一批独立起点复验所选短指令。目标范围在看过标定后、视觉训练前确定，并保留缺口。

冻结的留出行为门见项目设计。24 条回合左右各 12，要求每侧至少 11 条通过同一回合的方向、≤10°视线误差、胸部实际转向和末窗站稳。转向总限 9.6 s，撤令站稳限 1.2 s，检查全程非足力和末窗偏航。独立测试空场、中心、遮挡、换侧及左右切断/恢复。每一步登记眼图、意图、实际颈部交付、身体动作和物理测量。教师使用评估真值，部署仅用延迟发布眼图。

## 用户重申真实颈部后的实施界限

正式视觉闭环的任务信号须实际走受连接组约束的通路。首课用 BANC v888 左右 DNa02，逐根绑定原始身份、双颈截面、下行方向和可追溯的腹侧神经索突触靶点。人工脑的活动编码和身体侧读出属于两端工程适配。已准备的 2 ms 队列及左右信号直接译码可供软件与身体对照。正式结构闭环要使身体侧读出依赖经登记路径实际交付的信号，并对源边核验版本、方向和两端身份。原始边表版本尚未由相同 ID 本身独立证实，详见 `DNa02_TARGET_INVENTORY.json`。形态、拓扑、时间传输参数和生理数据分别登记。

首课只涉及两条已选的下行。未来的身体上行按新任务逐根绑定和实测；完整颈束、膜动力学和电极映射各自保留独立结论。正式对照在相同初态和刺激下比较通路完整、切断和恢复，记录脑输出、已交付信号、身体动作和站稳。眼图继续直接进入头侧人工脑。范围为人工搭建大脑项目，不混入开源脑重训练或翻译层。
