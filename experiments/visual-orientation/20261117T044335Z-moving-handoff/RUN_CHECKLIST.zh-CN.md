# 越箱恢复推进后的固定快照接管（P2、S5）

- 父实验为 20261117T032829Z 单箱完整示范和固定回放奖励配对。先验证已成功的右绕路线上的单一接管点。实际决策步 4,675，在 93.50 秒，半秒内已有连续颈后推进，红标可见并有全身尾缘净空。
- 同一个快照供教师原指令、中立指令、模仿、旧奖励 SAC、新奖励 SAC 五臂使用。固定冻结物理、双眼、AN/DN、动作读出、环境评分和随机种子。同一已验收示范布局。模型身份、SHA、实际载入脚本及环境版本见 INPUTS.json，编译与 XML 身份在各 fixture 的 IDENTITY.json。
- 原生仿真重放至快照。回放前缀使用已存档双眼图像，逐步与原始位姿、感觉、双向队列和命令比对，接管时验证待到图像与实时成像逐像素一致。快照包含完整原生求解数据、执行器增量状态和目标、物理时钟、运动路径跟踪状态、待收发队列、眼图缓冲与评分状态。之后用实时眼图，各模型用自己的 GRU 参数处理同一段到达历史。
- 接管后各臂上限 20 秒，保留原停滞、跌倒、触箱、站稳等门。全身尾缘净空至少 .03，实际推进至少 2 秒，质心净接近至少 .15 且原成功门通过为全通过。各臂首个继承的 5 ms 速度从自主推进扣除。12.5 µs 原生步、5 ms 颈后消费、20 ms 眼图与决策。
- 归档 drive.sh 使用 Python 3.12、MuJoCo 3.9、Torch 2.5 CPU、EGL 与单线程数值库。smoke.py 复现 4,800 原生步、执行器目标和逐包事件。replay.py 重放一条物理前缀，锁定快照后启动五进程从同一状态运行。每臂有尾段日志。随后 verify_handoff.py 独立复算，render.py 绘图并刻画实际身体关键时刻。PPO、GAE 和权重更新不适用。
