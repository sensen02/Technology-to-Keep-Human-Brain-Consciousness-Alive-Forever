# 真实视觉定向：最小神经行为方案（CODE_ONLY）

本文件仅为S4/S5视觉阶段设计，未导入Torch、NumPy、MuJoCo，未加载数组/模型、forward、生成图像、训练或物理。当前相机子代理41eeee96仅准备相机代码，真实相机probe通过前不冻结输入光学参数、训练数据或具体执行预算。本文不修改既有运动/气味权重与失败记录。

## 1. 最小在线链路

实际头部位姿 → 左右两路32×32 RGB实际渲染 → 固定数值归一化 → 小型共享视觉编码器 → 有序左右特征 → 慢GRU32 → Linear32→1 → tanh得到转向t → Torch ReLU投影[relu(t)/3,t] → 冻结运动ANN256 → 42有限增量PD → 真实完整身体 → 新头部图像。

第一版只做视觉，气味输入不接入行为策略。已验证的嗅觉行为权重66f423保留为独立冻结基线，不能混合其输出或把融合称为已实现。运动权重沿用789f：

相机光轴、视场、左右顺序、近远裁剪、像素通道与场景可见性必须由实际probe确认。左右视野必须保留有序信息，不先求平均消掉方向；不能预设它们就是真实复眼解剖。RGB只包含实际场景图像，不能含目标ID/轮廓标签/深度/segmentation/相机矩阵/方位数值/时间叠字。图像上的颜色、目标轮廓和遮挡由小网络学习，不用颜色质心、模板位置、像素几何规则或计算bearing产出动作。

建议单一首选编码器：每眼共享Conv3→8，kernel3/stride2/padding1，tanh；Conv8→8，kernel3/stride2/padding1，tanh；空间展平后Linear(8×8×8)→8。拼接有序左右8维特征成16维，再Linear16→32/tanh→GRUCell32；共享卷积权重允许左右使用同一视觉特征，拼接顺序使方向可辨。保留8×8空间分布，第一版不用全局平均池化，以免仅一眼可见或双眼重叠情况下丢失目标在视野内的位置。若相机probe表明两眼目标大小或覆盖不同，只在训练前声明实际输入参数，不事后按测试结果改架构。

## 2. 统一时序与输入延迟

建议CNN每20ms（50Hz）计算一次；行为GRU和运动网络每5ms（200Hz）推进，视觉特征在4个决策间保持。GRU使用原5ms慢更新alpha=1-exp(-.005/.1)，不能训练时每20ms一次、部署却每5ms一次而仍用相同alpha。视觉32记忆+运动256记忆共288；held RGB、16维特征和帧队列另作输入缓冲，不伪称新神经记忆。

为明确因果性，建议采用固定一帧发布延迟：物理时刻v捕获的图像只在v+.020发布；相同v时刻的神经决策仍使用上一次已发布帧。同步离线渲染即使墙钟立即完成，也不能让actor提前使用当前帧。每个5ms决策记录used_frame_id、capture_physical_time、release_physical_time、decision_time，要求release≤decision且capture≤decision-.020（浮点容差预登记）。目标在v变化仅作用于当时捕获的图像，经同一队列后影响策略，不可从环境标签额外发出命令。

完整1s稳定+4.8s教师+9.6s ANN保持。建议预热也50Hz真实采图维护队列，目标关闭，行为GRU保持初始；运动GRU按原真实身体输入连续预热。5.8s接管使用此前已捕获且此刻已发布的真实空场帧，不合成黑图替代未完成输入。撤辅、目标出现/消失、切换和遮挡均不reset行为/运动状态或队列。物理冻结时钟等待CPU渲染不会推进未来物理，但必须明确墙钟可能慢于实时，不能丢帧后仍标50Hz。

离线每条9.6s约480个相机发布间隔，对应1920个5ms神经决策；发布前一帧需由实际预卷空场帧提供。CNN只处理480个实际帧对，按发布索引将embedding重复供4次GRU更新，训练梯度回到相应帧编码器，不detach循环历史。若probe支持的最终API选择另一延迟，须在任何训练前版本化并让训练/部署/审核使用同一采样发布表，不静默换算。

## 3. 先离线真实图像，再身体闭环

第一门是相机probe：实际完整身体、左右光轴、目标左右变化、遮挡导致像素变化、目标后移/出视野/消失、图像读回顺序与延迟，模型物理数组前后不变。相机输入用实际渲染RGB；独立分割/几何只能用于审阅图像正确性，不进入actor。

第二门是有限离线长序列候选。建议预登记24条训练、12条留出配置，9.6s长序列覆盖空场、中心、左右出现后撤除、左右反转，目标bearing仅作离线教师标签；目标可见性/遮挡状态也仅用于标签和指标。先渲染实际目标与遮挡再保存RGB，不从标签画伪图。场景位置/大小/照明/出现时刻按完整片段分组留出，不能把相邻帧随机分到训练与验证。空场重复明确非独立重复。固定帧与左右眼交换对照不用于挑成功候选，首次训练前明确其评估方法。

气味历史显示1.2s只出现数据无法保证9.6s定向后自然回落；这里从第一版就保留长off尾、遮挡、反转和完整循环历史。候选损失按ON/过渡/规定恢复窗/空场尾均衡分配，预登记分段质量和边界，避免长已恢复尾段稀释短恢复窗。左右同配置的脉冲和反转组成对，固定成对采样batch；保持每条episode相同边际权重。可用action MSE+.01 latent MSE到atanh(clipped teacher target)，权重/目标幅度在训练前冻结，不在线做目标消失门控。

建议初始资源预算为单个架构候选、batch2或4、full1920step GRU BPTT、固定500更新，save0/250/500只final验证；实际预算待camera probe及一次受控内存/单步成本测量后预登记，不能现在宣称该预算已运行。正式训练前核实际生产视觉时序/训练scan、全参数梯度、临时Adam、保存重放和帧索引一致。不是PPO，不引入无关PPO检查。

第三门在离线全部分项通过后，运行最多6个完整身体条件：空场、中心、左目标出现后撤除、右目标出现后撤除、左变右、右变左。保持原1+4.8+9.6、相机实时更新与所有记忆连续。其证据只证明受控视觉响应，不等于自由视觉导航、障碍回避或视觉气味融合。

## 4. 建议跑前冻结的功能门与对照边界

下面为提案，必须在任何对应结果前形成可执行版本；不得按视频结果反向调门。

- 目标方向可见后的合格稳定窗口，左右turn符号正确比例≥.90；可见性由环境离线指标声明，actor不接该标志。延迟从第一张已发布的方向可辨帧起算，命令正确响应≤2s；不能从尚未发布的capture或标签出现时刻算神经反应。
- 空场turn RMS≤.02，中心turn RMS≤.05；目标消失/完全遮挡后，从第一张已发布的撤除帧起.5—1s窗口turn RMS≤.05，左右均检查，完整off尾另报bias/峰值。遮挡本身可能具方向线索，需单独无目标遮挡物对照，不能自动把所有遮挡视为黑图。
- 左右身体条件相对匹配空场在预登记窗口各出现正确方向≥1°航向差；切换后≤3s出现相应反向身体效应。全部支撑/COM/推进、严格原生非足0/额外力0、六腿完整周期同时满足；原滑移≤.5及全部原指标单列。滑移FAIL既不能被藏掉，也不能用其FAIL直接替代视觉功能判定。
- 离线交换左右视野是诊断，简单眼交换不一定等价完整左右镜像：双眼光轴有重叠或每眼内部水平位置仍有信息时，预期需根据实际probe建立。另做明确的场景左右镜像与对应左右眼交换/水平翻转对照，分别报告，不能在结果后选择“应当反转”的变换。
- 固定帧对照持续重复同一真实frame并保持GRU演化。它可显示策略对新图像更新的依赖，但单帧可见目标可能合理地引发持续turn，不应强行规定固定帧一定turn0或必失败。用目标反转/消失而actor仍固定旧图的配对条件比较真实与固定视觉，不能把命令持续当作违例伪造。
- 先保存全部离线对照；真实6回合外如需遮挡/固定帧/交换的身体因果对照，另立有限新增预算，不把离线网络对照冒称真实身体已完成。

## 5. 记录、独立验证与资源

原始输入保存uint8 RGB和相机规格/左右顺序/实际headpose/capture-release时刻，actor前固定归一化声明。1920个决策保留frame ID、held embedding（审阅/重放用途）、视觉32与motor256前后链、原始t/投影命令、实际42动作；1ms身体与原生峰值沿用原身份。目标坐标/遮挡参数单独环境诊断字段，记录与神经输入隔离。

先绑定所有源码、视觉scene-only变更/纹理/光照/相机参数、图像输入SHA、motor与视觉checkpoint、实际compiled数组；运行中不改源。保存后新进程从RGB重算CNN→GRU→命令→motor，核帧发布/状态链/动作和原指标。离线RGB重放只验证实际记录的网络因果路径；身体渲染的真实headpose采样还需同次源/几何身份和实际图像probe证明。

单CPU单线程唯一重任务，渲染、训练、审核、物理串行。24×480×2×32×32×3约70.8MB十进制uint8原始帧，不保存全量float64重复图像；按episode/帧分块、batch2或4解码，CNN每帧一次，特征按索引复用，避免每5ms重复存整张RGB或四次CNN。实际内存必须测，若不符预算先停在资源问题定位，不靠缩短9.6s窗口逃避恢复验收。避免预缓存有梯度的整数据集embedding；冻结视觉encoder时才可明确用无梯度缓存，但不能声称CNN仍在训练。

正式交付包含同次完整全身视频及实际双眼输入样例、受体替换为图像帧索引/turn/yaw同步曲线，实际打开图像与视频蒙太奇、全解码/时序/hash桌面副本核验。目标定向不证明识物、复眼生物有效性、视觉导航、停车或意识。
