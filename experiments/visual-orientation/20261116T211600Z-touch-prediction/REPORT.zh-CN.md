# 触觉预测与身体状态监督首轮

本实验属于人工搭建大脑项目。固定同一物理身体、起步站姿和下行 DNg100，测量无触、固定实体侧缘轻触、随机外侧探针接触和虚触四种同组回合。固定侧缘通过无遮挡参考轨迹选位，回合开始前确定坐标，运行期间不追踪足端。侧碰来自原生碰撞求解。关节角和角速度范围为六腿股胫铰链，负载为六足接触载荷，运动状态保留质心前速、逐足支撑、躯干直立和从真实前速得出的移动标签。

脑预测输入为两侧 AN06B002 实际到达的标量、有效位和脑内下行指令副本。模型作用于脑侧。试验性负载版本为每侧同一根源纤维上 .70 侧触 + .30 归一化前足负载，由另一条同身份队列实际交付，比较这种工程编码的代价。角度、角速度和六足运动状态作为未来 50 ms 的辅助标签，与真实体状态一起留档。脑侧没有直接身体状态输入。

四组 GRU 结构相同，分别为仅感觉、有序 DN 副本、置乱 DN 副本和混合负载输入。监督预测未来 20、50、100、200 ms 有无左右接触，并估计到达活动的 10%–90% 区间。训练每个 260 次 AdamW，独立加载所有权重作盲测，训练数据不含随机外来侧碰。外来侧碰用来检验压力条件。首轮固定侧缘对脑未提供单独视觉线索，模型读到的是到达的感觉历史和走停请求。

腿的角度与运动有各自的感觉编码来源。负载选择钟状感器作候选，当前试验未验证定量生理调谐。后续角度和角速度优先核验具名本体感觉上行。运动状态建议从这些输入和近期命令中估计，身体局部负载仍可用于步态反射。 [股胫本体感觉研究](https://pubmed.ncbi.nlm.nih.gov/30293823/) · [钟状感器连接研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8312698/) · [原项目训练设计](/run/media/sensen/Data2/cell_wound_prototype/RECOVERY_DESIGN.zh-CN.md:387)

20 组、每组四回合，合计 80 条、17,920,000 原生步和 44,800 个 5 ms 采样。12/4/4 组按完整成组回合用于训练、校准和留出，每组固定侧缘与随机探针都出现目标前足接触，所有虚触、无触及非前足探针碰撞为零。用保存的原生力独立重放一条留出触觉活动，脑侧数组逐值相等。2.525–2.610 s 切断为缺测，恢复后的首个有效采样在 2.615 s。 [样本审计](/run/media/sensen/Data2/cell_wound_prototype/experiments/visual-orientation/20261116T211600Z-touch-prediction/DATA_AUDIT.json)
