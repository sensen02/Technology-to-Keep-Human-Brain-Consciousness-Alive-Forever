# 触觉预测与身体状态观测（P1/P2、S4/S5）

真实来源 DNg100、AN06B002 和原 MuJoCo 12.5 μs、5 ms 记录。身体使用冻结局部控制、同名站姿，正常起走/撤令通过 DNg100；夹具移动或固定只作用于实体碰撞。四个条件同组为无触、固定侧缘、随机外侧探针、虚探针。用实体接触力标签独立审核。20 组 12/4/4 划分，组内四条不拆分。记录六腿实测股胫角、角速度、六脚载荷、前速、支撑位和姿态。除了两条既有 AN 和脑发 DN，不透传身体真值。工程对照用同一两根 AN 中每侧一个 .70 触觉+.30 归一化前足负载信号，初测候选，角度、速度和运动状态仍为监督标签。
- 模型均为脑侧因果 GRU，输入侧触、有效位、当前下行副本或遮蔽/乱序控制，外侧触碰作为独立压力窗口。260 次 AdamW，预测 20/50/100/200 ms，优先比较未触时的 100 ms AP 和 Brier。身体状态 50 ms 辅助监督。可读 GRU 权重和训练状态分别存档。
- 首个 1.7 秒工作样本的足端侧向跨度太小，固定夹具无法保持起点净空，退出 1。保留快照与清洁对照，新固定预算 2.8 秒、有限几何方向与安全距离，无途中重置。
- 固定权重、分组隔离、各模式相同容量。预测结果不改变此次执行器决策，独立记录下一步需要的异常检测与闭环验收。

## 实际执行与退出

- `./drive.sh collect.py DATA <组号>` 并行工作组 5、7 退出 0，其余局部固定探针搜索因起始净空不足退出 1。其无触参考立即归档。恢复脚本由唯一采集模块名修复历史 `collect` 导入重名，首次失败日志保留。六次 `./drive.sh recover_fixtures.py DATA <组号>` 对原始参考按完整足迹检索初始独立的固定位置，均退出 0，未改变采样物理预算。最终 80 条身份完整。
- `train.py DATA MODEL <模式>` 四条各 260 次、`train_zero_mass.py DATA MODEL_ZERO_MASS <模式>` 四条各 300 次，均退出 0，权重和优化器分别与训练日志、数据哈希或路径绑定。两轮独立 audit 正常退出，两轮主要 AP 达标门失败。命令均使用 `drive.sh`。
- `verify.py DATA DATA_AUDIT.json`、`assess_encoding.py DATA ENCODING_AUDIT.json`、两次权重因果重放与源码哈希核对退出 0。首版图标题参数错误退出 1，单独修正图形后导出首版和修正版同步图，实际打开检查。无部署、无神经梯度穿过物理或颈部。
