# 双前足触觉上行首课（P1/P2、S2/S5）

人工搭建大脑项目。冻结平地身体、双眼和 DNg100 走停策略，先校准上行读出。使用同一个原始站姿，保留原 71 网格主体、受限 42 执行器、5 ms 运动决策和 12.5 μs 原生步。受控球探针在近足局部随目标足移动，由实际碰撞施力。根和关节从求解器连续积分。探针运动是实验台刺激，保持在视觉输入中不可见。

- `touch_source.py` 取官方 BANC v888 原始 ID、官方 SWC、经核验的 v2 边表。逐条确定同一 SWC 分支跨两道截面，并登记真前足输入和脑侧靶点。传递采用固定源身份、工程 1 ms 时钟／2 ms 排队，投射计数按靶点归一。源不提供该场景的神经放电调谐。
- `probe_contact.cpp` 在实际求解步后记录外侧合力代理、指定接触对独立标签及非目标碰撞。部署的外侧接触读数不读取探针命令、触碰侧标签或真值检测。已有脚本的 AN 队列实际交付后才训练和读取两侧。
- 一次碰撞标签需指定目标前足和真实探针碰撞对达到 0.0001 W 并连续至少八原生步。把碰撞力在水平面的投影作为当前工程传感器代理，含其他环境接触的同类力；该代理不是实测受体电压。AN 发端取过去 1 ms 的已解接触力，脑侧仅取已到达的具名投射。
- 采 15 条训练、36 条留出，每个回合 675 ms。留出包括左、右、虚触各 12 条，与培训组错开深度和时机，部分回合有正常摆步；训练读出是每侧标量阈值，采用训练正例实际到达峰与无事件最高读数间的固定系数。正式门沿用方案左右各 ≥90%，错侧及负对照误报 ≤5%，延迟 p95 ≤60 ms。逐条报告实体刺激和效果，不丢弃不利场景。
- 走停验证使用相同视觉地标、实体左触保持上行完整、切断、恢复三次，另作右触和虚触。脑从触觉读出触发本课声明的停步策略。视觉和 DNg100 权重冻结。切断仅作用于 AN，未交付是未知，实际局部反射和身体路径运行。各回合终止和时间保存在登记。采用现有原站稳门。断续的因果比较以实际轨迹、意图、触觉和颈部队列为准。
- 环境为归档 Python `/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-walking-recovery/20261110T125712Z/env/bin/python`，MuJoCo，EGL 及 BLAS/OMP/MKL 单线程。
- `probe_contact.cpp` 用 `g++ -O2 -fPIC -shared -I"<env>/site-packages/mujoco/include" probe_contact.cpp <同环境 libmujoco.so> -Wl,-rpath,<MuJoCo 包目录> -o probe_contact.so` 构建，退出 0。首次源筛选以感觉元数据的 T1 字段匹配，原表感觉细胞该位为空，退出 1。旧代码与日志在 `initial_source_probe`，改用实际 `front_leg_*` 类别后退出 0。首个夹具快照扩维试验因增加 mocap 和全身力数组而失败，现按状态字段扩展并核对起始 qpos/qvel，140 ms 实体触碰探针退出 0（11,200 步）。
- 六个 `./drive.sh collect_touch.py DATA train|held ...` 进程及 `./drive.sh collect_touch.py DATA fit`、`./drive.sh collect_touch.py DATA audit` 退出 0。15 条训练、36 条留出，共 2,754,000 原生步。留出事件 24/24 正确、虚触 0/12，p95 4.0 ms。独立 `READOUT_REPEAT held 4` 54,000 步原始数据逐字节一致。 `READOUT_EVIDENCE.json` 锁定每条输入。固定门按事件评估。
- `touch_walk.py BEHAVIOR` 的五条实际轨迹和交付日志写完后，报告器遇到 NumPy 布尔值，退出 1，并保存首版源码及日志。布尔值转换后使用新目录 `BEHAVIOR_REPEAT` 独立积分全部五条。完整、切断、恢复、虚触和右触均使用同一个冻结的走停视觉网络、源绑定和已训练触觉读出。
- 五条重复试验及 `./drive.sh touch_walk.py BEHAVIOR_REPEAT audit` 退出 0。逐回合使用 `sha256` 核对原始与重复的姿态、动作、触觉、眼图数据及颈部队列记录，均相同。单次走停试验 5.31 秒、424,800 原生步。录像输入为确证的配对存档。
- `./drive.sh render_touch.py BEHAVIOR_REPEAT VIDEO_FULL` 退出 0。使用原身体可视几何和保存的探针坐标，无新求解步。实际打开左右对照关键帧，视频全解码 136 帧。桌面视频、关键帧和报告逐字节匹配。
