# SAC 接近目标的每步奖励复算

人工搭建大脑项目。以已通过的连续走、调速、左转后走和右转后走物理记录，复算 20 ms 决策步。只选颈后已有实际推进请求、头部仍在同一目标距离带外的步。单步复算统一使用既有 1.75–2.34 原生长度的目标带，排除到达、超时、碰撞等事件。四条轨迹的原文件先按验收哈希校验。此前通过的物理回合保留。

## 旧规则

在目标带外且未达到势函数截断时，e 为离目标带外沿的距离，旧的距离加时间项为

```text
r = (e_before − e_after) + 0.00045 × e_after − 0.005
```

以接近速度 .080 原生长度/s、步后距带外沿 1.0 为例。20 ms 实际接近 .0016，距离项加 .00205，时间扣 .005，净值 **−.00295**。要在该处拿到正值，接近速度要超过 .2275 原生长度/s，是当前实测前进档的近三倍。正常步速下，距离塑形有稠密变化，叠加时间之后正信号极少。

## 修订

追加一条实际获得过的最短距离记录。每比本回合此前最短的带外距离再缩短一单位，计 +4 分，单回合最多 +16 分。只在目标任务有效时计入。一次绕行允许短暂变远，随后重新超过旧最短距离才继续领用这一项。碰障、跌倒和过冲发生的当步不再加新进度。历史最短距离由环境计算。距带上沿、站稳及线路通过一起决定终点加分。

上述示例新增 .0064，净值变为 **+.00345**。同处原地站着仍为 −.00455。早期接近给即时反馈，带内等待站稳之后领取原成功回报。+4 及封顶 +16 是本轮用已有步速曲线校验的工程初值。

包括步态短暂回摆在内，全部测量窗口的平均每步净值也都从负转正。右转后的正分占比仍相对低，部分接近发生在追回已走过的距离时。重复回到旧最短点不会再次得到进度分。评分器在 14 个有原生接触记录的回放条件、20 个构造轨迹及 8 条联合脑卡滞回归上通过。宽坑卡滞、超大过冲、双箱碰撞仍得到原终止原因，已测试的失败回放总分仍为负。构造的同路往返只获得首次净接近的分数。

环境 Python 3.12、Torch 2.5.1 CPU、单线程，./drive.sh compare_distance.py、./drive.sh compare_distance.py --candidate、./drive.sh reward_audit.py 均退出 0。源码哈希与桌面副本已核验。本轮无新增物理积分或 SAC 更新。下一步可在有原生接触遥测的训练环境先复算单障碍绕行，再据实际回报分布校准进度上限。
