# 控制链与训练接口审计

本轮对应 S3（神经路径）、S4（感觉/执行接口）、S5（行为验证）。用户授权范围：先审计。没有重训、改连接组、修改身体或运行创伤。目录时间采用运行时 UTC；不据目录名称推断历史先后。结论基于当前磁盘源码、检查点和日志，不代表历史运行所有环境变量均可恢复。

## 主要结论

目前不能从站立/滑行动作的失败，推断真实连接组需要扩容。当前视频由替代 ANN 控制，连接组路线另有严重感觉信息损失；替代 ANN 路线则存在可复现的执行限幅和训练/评估不一致。优先修接口和训练管线，保持真实连接组拓扑不变，再决定是否训练神经参数。

## 1. 视频到底由什么控制

实际链：历史目标294维 → 冻结基础 ANN(294→128→128→42) → 预测关节目标；当前身体特征183维 + 历史目标294维 → PPO ANN(477→128→128→42) → 残差；两者合并为关节目标变化率 → 有界积分/有限PD → 42个关节电机 → MuJoCo。视频没有调用连接组运行时，不经过20k神经元、真实感觉端口或MN读出。

证据：`/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-walk-video/20261110T130000Z/render_walk.py` 第32–64、123–151行；训练实现 `/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-adh-namebug/20261110T150000Z/train_adhfix.py` 第79–112、172–176、375–386行。

实测动作 ANN 参数83114；包括价值头和42个logstd，优化器共83285个参数。基础 ANN 冻结，当前 PPO 不更新任何真实连接组突触/神经元参数。“fading_prior”标签不准确：C增加，但base_rate系数一直为1，未淡出基础目标。

## 2. 替代 ANN 感觉与记忆

183维 = 42关节偏移 + 42目标误差 + 42关节速度 + 42目标偏移 + 6足载 + 3重力方向 + 3身体线速度 + 3角速度。可获得当前足载、关节运动和平衡信息；没有显式足端位置、高度、切向滑速、吸附状态、速度指令vt或腿选择提示。足端几何可能由关节状态间接推断，但代码未提供已标定的此类编码。

证据：`/run/media/sensen/Data2/cell_wound_prototype/experiments/s5-ann-walk/20261107T091243Z/proprioception.py` 第9–43行；vt仅用于训练奖励，见上述训练文件第351、404–407行。

PPO本身是前馈MLP，无循环隐藏状态。294维历史是7帧×42的基础网络自己预测的目标，不是身体反馈历史；K=40、lags=[0,8,24,32,36,38,39]。正确200Hz更新时可跨约195ms，但没有MN/负载/真实关节历史。身体动力学、积分执行器、基础ANN反馈提供状态，不能因此说系统完全无记忆，也不能说已有神经时序控制。

负载标签存在腿序错位：实际传入LF/LH/LM/RF/RH/RM，感觉契约声明LF/LM/LH/RF/RM/RH。训练和渲染都使用前一顺序，所以本证据不证明训练/部署数值顺序彼此错位；但通道标签、逐腿解释与后续解剖映射不能信任，必须统一。

## 3. P0：执行器限幅使残差多数时候不能改变有效命令

训练请求 rate=(target−actuator.target)/.001+tanh(actor)*C/.001。C末值.02，名义残差可达20rad/s；外层CAP=30，但实际执行器默认max_rate=2rad/s，且训练/视频构造器未覆盖默认值。

证据：训练文件第129、228、383–386行；`/run/media/sensen/Data2/cell_wound_prototype/experiments/s5-ann-incremental/20261107T010000Z/incremental_actuator.py` 第98–99、134–136、170–191行。

最终检查点按训练时序做30tick确定性探针：1260个通道时刻中1217个请求超2rad/s；在相同实际状态下去掉actor修正，1210个通道时刻的限幅后变化率完全相同。此为局部命令敏感性证据，不是完整撤actor轨迹的长期因果结论。基础目标持续追踪与硬限速可能掩盖可学习修正，优先调整动作参数化及基网络混合方式；不能直接粗暴提高执行器速度上限。

实际增益/限力也不是一个统一常数：kp范围24.1238–149.2859，kd .02412–.14929，力矩限幅4.82476–29.85718（native，绝对SI NOT_ESTABLISHED）。之前用单个kp或统一14.93/29.86描述所有关节不准确。

## 4. P0：训练、评估、视频三条执行路径不一致

训练每5个1ms tick更新基础目标和历史；evaluate_policy每个tick更新（5倍刷新），且历史拼接在观测之后，训练在之前。视频使用200Hz，但历史缓冲从新解站姿初始化；训练和evaluate从原key姿态初始化。

证据：训练文件第150–170、297–310、368–377行；视频文件第73、135–139行。

同一最终检查点、相同身体和控制系数C=.02，在30tick探针中：评估对训练目标最大差0.259724rad、qpos元素最大差0.062926；视频对训练目标差0.019724rad、qpos最大差0.005643。qpos包含根位置、四元数及关节，不能把其混合元素差统一称角度。该探针不代表完整3.2s新验收，但足以证实时序和初始化不一致。

## 5. P1：训练信号和PPO时间尺度

- 当前日志w_duty=w_swing=0，实际没有抬脚/换步奖励。pad_bottom_z仍按旧单球精确名字查找，在三球身体返回六个0；当前权重为0所以不会影响现有奖励，但直接重新打开摆动奖励会无效。证据：训练第140–148、409–417行，当前TRAIN_LOG第2–8行。
- 1ms后gamma=.995、GAE=.95沿用：折扣时间常数约199.5ms，gamma*GAE权重时间常数17.76ms。不是“不能学习更长动作”的证明，但应按真实动作时间尺度重新选择并验证。
- rollout末非终止截断，最后一步nxt被写为0，没有用末状态value bootstrap，导致价值目标偏差。证据：训练第444、451–456行。
- slip_viol使用当前回合截至此时的累计均值，惩罚有未显式输入策略的历史依赖；足滑发生后后续步骤仍承担累计代价。需采用明确窗口/逐步成本并验证信用分配。
- 当前日志MIX_STATE=0、bank不存在，不能把其他回合的状态课程描述成这个最终检查点已经使用。当前只到v=.05第一层即停止，没有训练完整速度课程。vt未进入观测，后续即使跨层也不能据此声称具备可切换速度指令。
- summarize的forward取水平位移模长；反向或侧向漂移也可记作forward。门槛字段是均值support而历史文字常引用最小值；应分开报告，吸附对足载的贡献也要单列。

## 6. P1：训练步数被累计重复相加

训练第386行 total_steps += sim.steps，而sim.steps是本回合累计步数，每个tick又加一次。48×1024=49152决策，对应3932160次训练原生步；旧日志2015232000来自累计重复计数，不能继续称为20.15亿步训练。若计入一次控制评估和每16更新一次策略评估，当前源码下额外4×256000=1024000步，总物理步数条件重建为4956160；此合计依赖评估调用与日志对应，没有逐原生事件记录作为独立历史证明。

证据：`/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-adh-namebug/20261110T150000Z/LEVEL_0_v0.05/RESULT.json` 各decisions字段、训练第229–235、345、386、511–512、557行。原始日志不改写，本报告更正其解释。

## 7. 真实连接组路线：单独审计

真实路线是：q42+速度42+足载6 → 556个合格感觉细胞电流 → 20k身份/435126条严格来源边的电导脉冲网络 → 323个MN的滤波放电率 → 同腿MN读出 → 增量执行器。不是477维替代ANN的控制路径。

### 感觉信息在进入网络前已经丢失

`/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-local-learning/20261107T185910Z/encoder/encoder.py` 第238–258行：每腿只有膝角、coxa三轴归一化角度平均、膝速绝对值、足载四个独立标量，复制给同一类全部细胞。90个输入局部秩最多24；18个trochanter角和36个非膝速度完全不起作用，膝速正负不可区分，coxa三个轴存在精确平均混淆。556个细胞不等于556种独立感觉信息。不存在已实现的视觉、嗅觉、食物或能量感觉输入。饱和还可能进一步减小有效秩。

这直接影响走路：上抬与下落若只体现在膝速度符号上，会变成相同输入；不同coxa方向可能变成相同输入。读出层无法从完全相同的感觉编码恢复这些被丢掉的区别。应先依据注释和数据设计方向/轴调谐，工程假设另列，不得凭空编造生物调谐。

## 8. 实施建议与边界

先修统一控制入口、观测腿序、动作有效范围、截断bootstrap、成本记忆与计数，再用一条腿完成卸载—抬脚—摆动—落地的最小任务验证。修复必须另建派生版本及预登记，不覆盖旧模型。此轮没有实施这些修复。

真实连接组首轮保持身份与拓扑不变；感觉方向与关节轴信息丢失需先解决，映射缺口不得用虚构细胞/连接填上。之后可按已批准的参数学习范围训练明确的感觉增益、受限MN读出及有依据的神经动力学参数，分别标注工程假设。现有失败不能证明身体上绝对不可达，更不能证明连接组不可能学会走路。早期“唯一解释”“物理杠杆全部试尽”“闸门不可达”的强断言应降级为当时条件下未取得成功。
