# 第 1 轮（五）：单腿换步任务 **首次 3/6 通过**

接前四份报告。**重要前提，先说清楚**：以下结果是
**替代 ANN**（人工网络）、在**派生世界**（三球爪垫 + 可脱离吸附）里、由**声明过的有时序示范**初始化训练得到的；它**不是连接组能力**、**不是冻结身体验收**、**不是行走**、**没有做创伤**。验收判据从头到尾一个字没改。

---

## 一、先做上一轮承诺的事：把足端高度加进观测（`PREREG_OBS_V2.json`）

183 → **495 维**（+12：每腿爪垫底高、爪垫竖直速度，腿序 LF LM LH RF RM RH，除数 0.05 native 与 10 native/s，±10 饱和与其余感觉一致）。**冻结的 `proprioception.py` 未改**，**`encoder_v2.py` 与 556 细胞端口契约未改**——这是替代 ANN 的工程编码。

**自我更正（测量方法）**：上一轮我报的"足端高度线性可读 R² 0.6488 / 关节角 0.0594"是**用同一张线性映射去拟合六条腿轮换的样本**，映射无法知道问的是哪条腿，因此**对所有通道都低报了**。修正后的测量（`FOOT_HEIGHT_VISIBILITY.json`）：

| 输入 | 线性可读 R² |
|---|---:|
| 新加的爪垫通道（按腿提示选择） | **0.99999** |
| 全部感觉但去掉爪垫通道 | 0.648 |
| 只给关节角 + 腿提示 | 0.632 |
| 只给足载 + 腿提示 | 0.624 |

结论：爪垫高度现在是**直读**信号；而在改动前，它确实要靠其他感觉间接推断。

**观测 v2 的训练结果：仍然 0/6，放置率 0.000**（LF/LM/RF 抬升 1.8–2.2、末态承重 0）。→ 命中预登记结局 2：**可观测性不是瓶颈**。

## 二、于是我去检查示范本身——发现它从一开始就放不下来

`DEMO_CYCLE.json`：两相示范抬到爪垫高度 1.33 后，在 1.17–1.33 之间**来回振荡，从未落地**；所谓"下压"就是把抬脚方向取反，只能抵消 0.15。

`DEMO_SWEEP.json`（量级 × 切换点 15 组）确认**没有任何一组**能同时抬脚与落地：抬脚方向与其反向是同一个轴上的两半。

**改进**：下压方向改为**按当前姿态重算竖直雅可比**再取下降方向（`descend_direction`）。逐腿自检（`DEMO_PRESS.json`）：
- **LM 首次通过全部五条判据**；LF 末态承重 0.098（差 0.002）；RF 0.074。

再把"抬脚时长"扫一遍（`DEMO_TICKS_SWEEP.json`）：**抬 90 tick 时 4/6 腿通过**（LF/LM/RF/RH）。

**无时钟版尝试**（`DEMO_STATE_TEACHER.json` / `DEMO_STATE_SWEEP.json`）：把 90 tick 换成型态阈值（爪垫高度 0.03–0.20 × 前移 0.03）后**最多只有 LM 1/6**——**这个序列看起来真的需要时间信息**。

## 三、决定性实验：用有时序的示范，教一个**没有时钟**的网络

`PREREG_AMENDMENT_6.json` 声明了这一点。教师用 90 tick 定时；网络输入里**没有任何时钟或相位**。监督回归 MSE 0.0186（明显高于之前 0.001，因为示范的定时切换对网络不可观测——这正是实验要问的）。

**24 次更新后（三次评估 8/16/24 完全一致）**：

**3/6 通过：LF、LM、RF**（五条判据全过：卸载、抬升、前移、落地承重、安全）。训练内放置率 0.257（峰值 0.627），奖励在若干更新里首次为**正**。

**独立重放校验**（`verify_replay.py` → `REPLAY_CHECK.json`）：从保存的权重重新加载并评估两次，**93 个量逐位相同**；与训练日志的差别来自 checkpoint 用 float32 存权重（最大绝对差 6.4e-6），**全部布尔判定 0 处不同**；评估过程中**没有任何教师参与**。

## 四、这条结论能说什么、不能说什么

**能说**：
- 单腿"卸载→抬起→前移→放回承重"这个动作，在本派生世界里**对 LF/LM/RF 三条腿是可以做到并被网络自主执行的**；判据未改，重放可复现。
- 一个**没有时钟输入**的网络，能从一个有时序的示范里学出这个序列（示范 MSE 高、但仍被复现），说明策略并不需要一个显式计时器。
- 安全侧同时最好：COM 1.24–1.26（远高于 1.00）、非足接触 0.00 W（闸门 4.889）。

**不能说**：
- **不是行走**：这是一次单腿动作，发生在原地站立的身体上；四闸（0.5 滑移 / 0.9 支撑 / 4.889 W 非足 / 1.20 高度）**没有作为行走被评估**，冻结身体依旧未通过任何行走验收。
- **不是连接组**：这是替代 ANN，观测里的爪垫通道是工程编码；encoder_v2/556 细胞未参与本轮。
- **不是从零学出来**：序列来自声明过的示范（教师有时序），网络是模仿起点 + PPO 微调；教师本身通过 4/6。
- **不是生物量级**：绝对力值仍是 NOT_ESTABLISHED。

## 五、还剩什么

1. **LH/RH/RM 三条腿**：RH 只缺前移（前移 0.0），LH 抬不起来（0.0021），RM 抬了放不下。后腿单抬会让身体后倾、腹部触地——这仍是它们的主要障碍，需要"重心前移"作为前置相位。
2. **六条腿同时**：现在是一次一条腿、原地站立；连续的六腿慢走还没开始，滑移闸门也还没被触碰。
3. 下一步：把 RD（右后）与 RM 拆成"重心前移 + 抬脚"两段示范并同样做教师自检，再用同一套流程训练。
