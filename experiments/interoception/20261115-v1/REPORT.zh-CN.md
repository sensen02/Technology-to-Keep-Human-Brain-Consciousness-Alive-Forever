# 人工果蝇内感觉模型 v1

本次实现属于人工搭建大脑项目。模型将身体观测转换为供局部网络使用的本体感觉特征，并通过独立器官台架计算心壁运动和消化道扩张代理。源码在 `engine/embodied/interoception.py`。

| 部位 | 当前输入与输出 | 接口身份 |
|---|---|---|
| 六腿股胫关节 | MuJoCo 具名铰链角与角速度，按腿输出屈曲位、伸展位和两个方向的运动强度。共 24 路，按关节限位和工程速度标度归一化。 | 身体局部感觉。参考果蝇 FeCO claw 位置和 hook 方向敏感性。代理幅度待生理校准，上行神经元身份未绑定。 [腿感觉连接研究](https://doi.org/10.1038/s41467-025-59302-3) |
| 心脏 | 外部测量或模拟提供归一化心壁直径和有符号的变化率，编码直径、扩张与收缩。缺失输入时输出空值。 | 诊断侧。心壁直径可测，心脏感觉神经元及颈部上行通路的映射未知。 [果蝇心壁光学量化研究](https://pubmed.ncbi.nlm.nih.gov/19317655/) |
| 咽部 | 咽泵腔内容量与容量之比作为扩张代理。入口与吞咽开度控制台架里的物料流。 | 头部局部工程感觉。成人果蝇咽泵 md-C 机械感觉参与吞咽，有对应现象证据。当前扩张比例为工程近似。 [果蝇咽部机械感觉研究](https://elifesciences.org/articles/88614) |
| 嗉囊、中肠、后肠 | 三段分别跟踪内容量、容量和流动，输出归一化扩张。 | 嗉囊与中肠映射待绑定，后肠首版为诊断。嗉囊和前中肠的 Piezo 牵张证据提供后续校准方向。 [果蝇肠道牵张原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7920550/) |

`FlyInteroception.observe` 接收一个时间戳，逐腿的 `JointSample`，以及可选的 `HeartObservation` 和 `GutState`。`MujocoTibiaSensors.read` 可使用在线或保存的 `qpos/qvel`。输入缺失保持 `None`，静止或空器官的实测零可保留为零。`frame.local_inputs("body_local")` 取六腿局部特征，`frame.local_inputs("head_local")` 取咽部头侧代理。心壁和待绑定的肠道读数可在 `frame.samples` 中监测，跨颈运行端口当前为零。

`DigestiveCompartments.advance` 对咽腔、嗉囊、中肠和后肠维护同一任意体积单位的账本，每次输出实际进入、吞咽、各段转移和末端排出量。各段只转出采样开始时已有的内容物。台架没有器官组织力学、吸收或代谢功能。心脏目前从外部接收观测，由未来身体器官模型或实验数据提供驱动。

## 实测验证

- MuJoCo 3.9 编译规范肌肉版和已归档行走版。两版六条股胫铰链的几何扫角都验证了正方向是屈曲。逐腿正负运动探针只改变对应腿的感觉输出，读取前后物理状态相同。
- 读完已验收的 15,400 帧行走记录，其中 9,600 帧属自主期。24 个通道在自主期都观察到变化，归一化范围及运动方向互斥均通过。自主期没有胫节角越过标称限位。
- 心壁台架区分静止、扩张、收缩，心壁变化不进入两个局部神经输入。关闭吞咽时只填充咽部，开启后内容物依次进入各段。1,400 个 10 ms 步的累计最大物料守恒误差为 4.77e-14 工程体积单位。

原始结果与输入哈希在同目录 `RESULT.json`。执行命令退出 0。行走轨迹是只读输入，训练更新和整蝇物理积分均为零。供体资产使用相同文件身份。

```bash
/run/media/sensen/Data2/cell_wound_prototype/experiments/banc-walking-recovery/20261110T125712Z/env/bin/python -B /run/media/sensen/Data2/cell_wound_prototype/verify_fly_interoception.py
```
